## 3. 보안 (독립 감사 에이전트, 코드 정독 + node 실측)

> 정적 클라이언트 게임이라 서버·계정이 없다. "중간" 등급 XSS 도 피해자가 **공격자의 일지 파일을 직접 가져와 확정**해야 하고, 피해는 게임이 호스팅된 origin 의 브라우저 저장소·화면에 한정된다(origin 을 공유하는 호스팅이면 그 범위로 넓어짐).

|---|---|---|---|
