## 변경: 1번 「라코코 표정 초상」은 의상별로 필요

신의상 4종은 모두 머리 장식이 있어(메이드 토끼귀 헤드피스 · 경찰 모자 · 유령 베일 · 수녀 머리 덮개) 상반신은 물론 얼굴만 잘라도 차이가 난다. 기본 의상 초상만 있으면 신의상을 입은 동안 어긋난 모습이 나오므로 **의상마다 따로** 필요하다.

| 항목 | 내용 |
|---|---|
| 수량 | 의상 5종(기본·유령·메이드·경찰·수녀) × 표정 5종 = **25장** |
| 우선순위 | **1차: 표정 3종(기본·웃음·당황) × 5 = 15장** — 결과 화면의 대성공·아쉬움 반응을 모두 낼 수 있음. 2차: 놀람·뿌듯 10장 |
| 규격 | 정사각 512×512 상반신, 투명 PNG, 기존 도트풍 |
| 경로·이름 | `assets/characters/faces/rakoko-face-{의상}-{표정}.png`<br>의상: `base` `ghost` `maid` `police` `nun` · 표정: `default` `smile` `flustered` `surprised` `proud` |
| 쓰는 곳 | 사건 카드 머리말, 결과 화면(대성공=웃음·뿌듯, 아쉬움=당황), 응원·공개 순간 |
| 빠진 그림 처리 | **지금 입은 옷의 초상이 없으면 다른 옷 초상으로 대체하지 않고 초상 자리를 비운다**(어긋난 옷 방지). 그래서 일부만 먼저 줘도 된다 |

v1의 1번 이름 규칙(`rakoko-face-{표정}.png`)으로 이미 만든 그림이 있으면 **기본 의상** 것으로 보고 `rakoko-face-base-{표정}.png`로 연결한다.
