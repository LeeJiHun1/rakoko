# 라코코의 방송일지 — 말투 가이드

> 최신 v0.2: 잠정 관찰 10개. 원음·화자 검증 0건. 아래의 v0.1은 초기 본문이며 맨 아래 추가 관찰이 최신 보강이다.

버전: 0.1 · 작성일: 2026-11-03 (한국시간) · 상태: 자동자막 문맥을 읽은 초기 가설, 음성 대조 전

## 1. 이 문서를 사용하는 방법

목적은 팬게임의 창작 대사에 사용할 언어적 습관을 근거와 함께 정리하는 것이다. 실제 인물의 내면을 복제하거나 모델을 훈련했다는 뜻의 ‘학습 완료’가 아니다. 수집·분류·근거 검토를 뜻한다.

사용자가 지정한 원천은 [라코코의 코코팜 다시보기 채널](https://www.youtube.com/@RAKOKOrakoko)이다. 영상 제목, 자동자막, 외부 문서를 구분한다. 원본 음성과 화면을 직접 대조한 구간은 현재 0건이다.

**이 문서의 모든 말투 관찰은 잠정적이다.** 자동자막에서 읽은 문장을 본인 발언으로 확정하지 않는다. 도네이션 TTS, 영상 도네이션, 게임 대사, 합방 상대의 발언이 섞인다. 특히 자막의 `>>`는 화자 이름이나 ‘시청자 발언’의 확정 표지가 아니다.

게임의 소재에서 오컬트를 제외한다는 사용자 요구를 유지한다. 기존 방송에 오컬트 관련 단어가 등장한다는 사실을 게임 소재로 쓰라는 허락으로 해석하지 않는다.

## 2. 근거 등급

| 등급 | 의미 | 사용 범위 |
|---|---|---|
| A | 원본 음성·화면과 화자까지 대조 | 정확한 발음·억양·말 고침을 기술할 수 있음. 현재 없음 |
| B | 자동자막의 전후 문맥을 읽음 | 대화 구조의 잠정 가설. 정확한 인용·발음 확정은 금지 |
| C | 제목·설명·외부 문서만 확인 | 분석할 영상 선정용 |
| U | 사용자 제공 조건 | 기획 제약으로 적용. 실제 방송 발언을 확인했다는 뜻은 아님 |

원문을 장문 재수록하지 않고 요약과 타임스탬프를 남긴다. 자동자막의 오기를 그럴듯한 표현으로 임의 복원하지 않는다.

## 3. 우선 발견한 대화 구조

### S01. 당황할 때 문장을 멈추고 다시 시작하는 구조

- 근거: [1월 18일 00:12:00–00:16:20](https://www.youtube.com/watch?v=Kv03yHk6Fe8&t=720s), [1월 22일 00:05:50–00:06:50](https://www.youtube.com/watch?v=-KemMFgrOII&t=350s).
- 관찰: 설정을 설명하다 중단하고, 잠시 기다리라고 요청하거나 같은 의미를 다시 말하는 흐름이 보인다.
- 해석: 완성된 장문 독백보다 반응 → 중단 → 재설명의 짧은 호흡이 어울릴 가능성.
- 적용: 사고 발생 직후 첫 대사는 짧게, 그다음에 상황 설명을 둔다. 모든 대사에 말더듬을 넣지는 않는다.
- 확신도: 중간. 반복되는 구조는 읽히지만 발음과 실제 간격은 미확인.

### S02. 사과와 설명이 교대로 나오는 흐름

- 근거: [5월 10일 00:02:20–00:03:30](https://www.youtube.com/watch?v=28oEgK4mT-o&t=140s), [10월 5일 00:03:10–00:07:10](https://www.youtube.com/watch?v=pjLUfFY0pG4&t=190s).
- 관찰: 늦은 상황을 둘러싼 장난 사이에서 사과와 경위 설명이 교차한다.
- 적용: ‘즉시 사과하기’와 ‘상황 설명하기’를 서로 배타적인 성격 선택으로 만들지 않는다. 설명하다가 사과하는 연속 반응이 가능하다.
- 주의: 시청자가 요구한 벌칙이 실제로 전부 수락됐다는 뜻은 아니다.
- 확신도: 중간.

- 근거: [6월 11일 00:43:00–00:45:10](https://www.youtube.com/watch?v=ix7-CJW3Mjc&t=2580s), [9월 10일 00:02:00–00:05:50](https://www.youtube.com/watch?v=NVwuL1_SHZY&t=120s), [10월 21일 00:03:35–00:04:35](https://www.youtube.com/watch?v=kbxwJpapjCo&t=215s).
- 관찰: 자기 이름을 사용하는 표현, 팬을 향한 직접 호칭, 편한 말과 감사 표현이 함께 나타난다.
- 적용: 자기 이름을 쓰는 표현은 인사·장난·관계 강조 장면에 제한적으로 배치한다. 모든 문장의 주어를 ‘코코’로 고정하지 않는다.
- 확신도: 중간. 팬덤명은 자동자막에서 여러 형태로 오인된다.

### S04. 감사 표현이 진행 중인 이야기에 끼어드는 흐름

- 확신도: 중간. 행사 영상은 외부 음성이 섞일 가능성이 있어 화자 확인을 우선한다.

- 적용: 게임 내 공지·일정 안내에 별도 말투를 둔다. 계약 관련 실제 사건을 개그로 각색해도 된다는 뜻은 아니다.
- 확신도: 중간. 정확한 공지 문구는 음성·공식 원문 대조 전까지 인용하지 않는다.

## 4. 창작 대사 작성 규칙

아래는 게임 작가용 제안이며 실제 발언을 인용한 것이 아니다.

1. 상황을 먼저 쓴다. 같은 표현도 사고·감사·피로·공지에서 의미가 달라진다.
2. 한 번의 반응은 1~3문장을 기본으로 한다. 중요한 설명은 더 길어도 된다.
3. 말 고침은 실제로 무언가를 정정할 때 사용한다. 장식용 말더듬을 반복하지 않는다.
4. 장난을 받은 뒤의 반응을 여러 갈래로 둔다. 수락만이 정답은 아니다.
5. 감사와 진행 복귀를 한 세트로 쓴다. 알림이 오면 원래 이야기를 영원히 잊는 캐릭터로 만들지 않는다.
6. ‘잉짜’ 등의 고유어는 음성 대조 후 표기를 확정한다. 자동자막에 나온 표기를 기준으로 새 유행어를 만들지 않는다.
7. 웃음·비명 표시는 자막 시스템의 분류일 수 있다. 실제 감정 강도의 증거로 사용하지 않는다.
8. 욕설·성인 농담은 빈도와 맥락을 검증하기 전 기본 말투로 고정하지 않는다.

창작 예시 — 방송 화면이 뒤집힌 상황:

> “아, 잠깐만. 이거 왜 거꾸로야? 조금만 기다려 봐, 다시 맞출게.”

창작 예시 — 팬의 과장된 요구를 끊고 진행하는 상황:

> “그건 또 무슨 소리야. 일단 준비한 거부터 하자.”

이 문장들은 ‘라코코가 실제로 이렇게 말했다’는 자료로 재사용하면 안 된다.

## 5. 아직 확정하지 않은 항목

| 항목 | 필요한 검증 |
|---|---|
| 정확한 어미·혀 짧은 발음 | 서로 다른 날의 원본 음성에서 반복 확인 |
| 웃음·침묵·말속도 | 오디오 파형·재생 대조. 자막 타임스탬프만으로 판단 금지 |
| 반말·존댓말 전환 기준 | 상대와 상황이 확인되는 연속 대화 검토 |
| 도네이션 성대모사·낭독 | 본인 주장과 읽어준 말 분리 |
| 1월과 10월의 말투 변화 | 같은 유형의 장면을 시기별로 맞춰 비교 |
| 밈별 실제 사용 빈도 | 화자 분리 완료 후 집계. 원시 검색 횟수와 혼동 금지 |

## 6. 품질 점검과 다음 작업

- 1월, 3월, 5월, 7월, 9월, 10월에서 인사·감사·거절·실수 수습·진지한 안내를 균형 있게 뽑는다.
- 먼저 10개 구간을 30~90초씩 음성과 대조한다. 깨끗한 독백, BGM, TTS 겹침, 합방을 포함한다.
- 원문 단어 오류와 화자 오귀속을 따로 기록한다. 직접 듣기 전 정확도 백분율을 제시하지 않는다.
- 검증된 대사 예시와 게임용 창작 예시를 별도 칸에 보관한다.
- 각 가설에는 반례를 찾는다. 초기 방송의 당황한 장면만으로 전 시기의 성격을 확정하지 않는다.

자동자막은 탐색용으로 유용하지만 실제 발화와 다를 수 있다. [YouTube 자동자막 안내](https://support.google.com/youtube/answer/6373554?hl=ko). [DownSub](https://downsub.com/)는 기존 자막을 추출하는 도구이므로 같은 트랙을 받는 것만으로 인식 품질이 좋아지지는 않는다.

### S10. 모든 장난에 반응하지 않는 진행

실제 발음 표기는 늘리지 않았다. 자동자막의 반복 횟수·감정 태그·TTS가 섞인 표현은 고유 말투 빈도에 합산하지 않는다.
