# 〈라코코의 방송일지〉 데이터 수집 설계

작성: 2026-11-03 · 80억분의 1 v0.9.17 직접 플레이 기반 초안

## 핵심 결론

현재의 사건 카드 수집만으로는 부족하다. 방송이 평소 어떻게 흘러가고, 준비·장비·연습에 무엇을 쓰며, 선택의 결과가 다음 방송에 어떻게 남는지를 함께 모아야 한다. 게임은 **평소 운영 → 사건 발생 → 선택 → 즉시 반응 → 지속 상태 변화 → 후속 사건 → 방송일지 결산**으로 설계한다.

이 문서의 게임 규칙과 목표 수량은 제작 제안이다. 라코코의 실제 행동 확률이나 개인 성향을 측정한 결과가 아니다. 심각한 사건과 오컬트는 소재에서 제외한다.

투자 방식은 실제로 예금에서 주식·채권 혼합으로 바꿨고 선택 표시와 변경 안내를 확인했다. 직업훈련은 돈을 써 실행한 뒤 수료 안내와 2년 대기를 확인했다. 별도 도전 준비 후 다음 해 크리에이터 도전 카드를 직접 선택했고 실패 후 기존 직업이 유지되는 결과를 보았다. 이들은 단순한 일회성 능력치 증가와 다른 구조다.

정확한 추첨 가중치, 전체 사건 수, 모든 엔딩, 숨은 수식은 UI 플레이만으로 확정할 수 없다. 특히 선택 전후에 여러 자동 사건이 함께 발생하므로 수치 차이를 특정 선택의 고정 효과라고 역산하지 않는다.

실제 소득·자산·지출을 추정해 원작의 금융 시스템에 맞추지 않는다. 공개된 장비 구매나 준비 언급이 있어도 금액이 없으면 미상으로 둔다. 게임 비용은 ‘준비 포인트’ 같은 창작 단위로 별도 조정한다. 합방 상대는 공개 협업 정보만 기록하며 친밀도나 사적 관계를 추정하지 않는다.

## 3. 사건 하나를 채택할 때 필요한 기록

1. **식별**: 사건 ID, 방송일, 영상 ID·URL, 시작·끝 시간, 콘텐츠 구간.
2. **발견 경로**: 외부 글 원주소·게시일·작성 주체, 다시보기에서 대응 구간을 찾은 방법. 외부 검색이 없는 자막 직접 발견은 그대로 표시.
3. **사실**: 직전 상황, 실제 발화자, 실제 행동, 즉시 결과, 방송이 다음에 어디로 이어졌는지.
4. **선택 구분**: 실제 실행 / 제안만 함 / 거절 / 실행 여부 미상. 편집이나 자막 누락도 표시.
5. **지속 요소**: 필요한 장비·게임 경험·자료·다음 방송 약속·반복 도전 ID.
6. **말투**: 본인 반응의 구간, 질문·부정·설명·감사의 순서, 창작 대사 참고용 특징. 긴 원문 복사는 피함.
7. **검증**: 자동자막 확인 여부, 원음·화면·화자 확인 여부, 대안 해석과 남은 의문.
8. **각색**: 창작 상황·선택지·즉시 효과·후속 조건·재등장 대기·중복 금지. 사실과 분리.

현재 B=자동자막 맥락 확인, C=제목·외부 단서, A=원음·화면·화자 대조 기준을 유지한다. 원음으로 확인하지 못한 자막 문장을 대표 말버릇이나 직접 인용문으로 확정하지 않는다.

## 4. 중요한 전환: 사건 수보다 ‘연결 정보’

기존 카드 24개는 상황과 선택지 초안이다. 아직 확률형 시뮬레이션의 규칙 데이터로 완성된 것은 아니다. 다음 항목을 우선 보완한다.

| 기존 소재 | 다음에 수집할 내용 | 가능한 게임 구조〔창작〕 |
|---|---|---|
| 모니터 화면 문제 | 문제 직전 설정·복구 시도 순서·대체 진행·나중에 해결됐는지 | 점검 상태에 따라 수습 경로 변경. 원인 미확인 상태에서 고장 확률을 단정하지 않음 |
| AI 사진 맞히기 | 정답 공개 전 판단 이유·장비 사용·틀린 뒤 반응·실제 규칙 | 도입→감별→정답 공개→결과 대사. 시선 장비는 준비 조건 |
| 테란 첫 도전 | 기본 조작→팁 수용 여부→막힌 부분→재시도 | 연습 포인트와 숙련 상태가 다음 판 선택에 영향 |
| 콘텐츠 기획 | 제안된 아이디어·채택/보류·후일 실제 진행 | 아이디어를 저장하고 다음 방송 후보로 예약 |
| 트리가드 도전 | 중간 전술 변경·휴식·성공 장면·실패마다 다른 반응 | 재도전 횟수 단계와 학습 상태, 성공 시 한 번만 나오는 회수 카드 |
| 생일 방송 | 축하 도착→읽기→감사→진행 재개, 반복 대사와 특별 대사 | 달력 고정 이벤트와 분위기 회복, 실패·벌칙 소재로 만들지 않음 |

연속 사건에는 ‘이미 성공했으면 재등장 금지’, ‘장비를 준비한 경우만 등장’, ‘같은 날 같은 해프닝 반복 금지’ 같은 조건이 필요하다. 이는 방송 사실이 아니라 게임 설계 규칙이며 별도 필드로 저장한다.

## 5. 빈도와 확률을 다루는 방법

### 능동 관리 메뉴를 위해 별도로 찾을 10가지 장면

아래는 수집할 장면의 목록이다. 라코코가 모두 실제로 했다는 뜻은 아니다. 실제 사례를 못 찾으면 가상 행동으로만 남기거나 삭제한다.

| 수집 대상 | 확인할 질문 | 관리 행동 후보〔창작〕 |
|---|---|---|
| 방송 설정 점검 | 무엇을 설정했고 방송 중 문제가 줄었는가? | 방송 전 점검 |
| 화면·장비 조정 | 장비가 실제로 언제부터 사용됐고 어떤 콘텐츠에 필요했는가? | 장비 준비 |
| 게임 연습 | 연습한 내용이 다음 도전에 반영됐는가? | 연습 시간 배분 |
| 콘텐츠 자료 준비 | 사진·질문·영상·문서 중 무엇을 미리 준비했는가? | 자료 제작 |
| 팬카페 탐색 | 글을 읽다가 다음 방송 소재로 채택한 사례가 있는가? | 아이디어 수집 |
| 합방 준비 | 역할·시간·게임 규칙을 사전에 맞췄는가? | 합방 일정 잡기 |
| 편집·화면 구성 | 자막·OX·글꼴·화면 효과가 어떤 목적에 쓰였는가? | 전달력 개선 |
| 일정 재조정 | 콘텐츠가 길어져 무엇을 미루거나 줄였는가? | 진행 순서 변경 |
| 새 콘텐츠 시험 | 작은 시험 후 정식 콘텐츠로 이어졌는가? | 파일럿 방송 |
| 기념 방송 준비 | 준비물이 실제 진행·감사·회고에 어떻게 회수됐는가? | 기념일 준비 |

원작의 지속 투자 구조는 ‘연습을 계속하면 숙련이 쌓임’, ‘준비 자료가 있으면 관련 카드가 열림’처럼 옮길 수 있다. 실제 주식 투자나 부채 시스템을 넣을 근거는 현재 없다. 준비 포인트가 부족하면 다음 방송으로 미루는 가벼운 제약이 사용자 요청에 더 잘 맞는다.

재미있는 클립만 보면 모든 방송에서 사고가 나는 것처럼 편향된다. 월별로 사건이 없는 평범한 방송도 포함하고, 관찰한 구간 길이와 방송 수를 함께 적는다.

- 관찰 빈도는 ‘검토한 10개 방송 중 확인한 2개’처럼 분모를 표시한다. 채널 전체 발생률로 확대하지 않는다.
- 한 번 본 선택은 100% 성향이 아니다. 서로 다른 날짜의 반복 사례와 반대 사례를 같이 찾는다.
- 영상 제목의 숫자, 자동자막의 숫자, 실제 화면의 숫자를 분리한다.
- **현실 관찰 빈도와 게임 등장 확률은 별개다.** 게임 확률은 즐길 만한 분포와 중복 방지를 위해 플레이테스트로 조정한다.
- 특정 실제 인물의 ‘호감도’나 위험을 확률로 수치화하지 않는다. 방송 분위기와 게임 내 협업 준비 상태로 표현한다.

## 6. 권장 게임 범위와 수집 목표

첫 버전은 한 번에 15~25분 동안 가상의 여러 방송일을 보내고 ‘오늘까지의 방송일지’를 받는 형태를 제안한다. 원작의 출생·노화·죽음을 가져올 필요는 없다. 라코코의 실제 활동 연표는 참고하되 플레이어 선택으로 달라진 경로는 가상이라고 명시한다.

프로토타입 수집 목표〔완료 수량 아님〕:

- 평범한 방송 흐름 12회: 서로 다른 달과 콘텐츠를 포함.
- 가벼운 사건 40~60개: 장비 해프닝에 치우치지 않게 분산.
- 3~5단계 연속 사건 5묶음: 게임 재도전·콘텐츠 준비·합방 준비 등.
- 준비/관리 행동 10개 안팎: 시간·준비 포인트·장비/자료 상태를 소비하거나 바꿈.
- 반응 유형 8개 × 서로 다른 날 3사례: 승리·실패·당황·감사·놀림 대응·정정·선택 고민·마무리.
- 회고 재료 10개: 시작 때 언급한 일이 나중에 회수되는 장면과 반복 밈.

기본 자원은 준비 포인트·진행 여유·게임 숙련·방송 분위기 정도로 시작한다. 에너지 같은 수치는 게임용 추상 자원으로만 설명하고 실제 건강 상태와 연결하지 않는다. 장비 안정성은 실제 결함 진단이 아니라 준비 여부를 표현하는 가상 상태다.

마무리는 ‘게임 도전이 기억에 남는 시즌’, ‘팬들과 수다를 많이 나눈 시즌’, ‘새 콘텐츠를 많이 시도한 시즌’처럼 플레이 기록을 요약한다. 단일 성공 점수나 파국 엔딩보다 선택의 흔적을 돌려주는 방향이 어울린다.

## 7. 조사 진행 순서

1. 확보 자막 81편에서 평범한 방송 구간과 기존 24개 카드의 전후 맥락을 추가 채집한다.
2. 구독·장비·AI 감별·테란·기획·생일·보스 도전 7개 묶음부터 원음·화면 검증 대상을 정한다.
3. 같은 게임/약속이 등장하는 다음 방송을 연결해 후속 결과를 찾는다.
4. 말투 가이드는 상황별 반응 묶음으로, 판단 가이드는 상황→실행→결과→예외 구조로 보완한다.
5. 외부 사건 문서는 공지·날짜·다시보기 대응을 유지하며 게임 채택 여부를 별도로 기록한다.
6. 사건 카드에 조건·지속 상태·대기·후속 ID를 붙인 후 소규모 플레이테스트로 등장 빈도를 정한다.

YouTube 접근 제한 중에는 새 요청이나 우회를 하지 않고 로컬 자료와 공개 외부 근거를 사용한다. 자막만으로 완료할 수 없는 검증은 미확인으로 남긴다.

## 8. 이후 합의: 단계별 사건 확장과 다중 엔딩

**추가 확정 제약:** 사용자는 다른 캐릭터로 환생하는 구조가 민감하다고 명시했다. 라코코의 정체성·활동 캐릭터는 끝까지 유지한다. 환생·타 캐릭터 재데뷔·정체성 교체를 성장 분기나 엔딩으로 넣지 않는다. 콘텐츠·도전·합방·기획을 확장하는 방식으로 분기한다. 참고 게임에서 그 경로를 플레이했어도 라코코 게임에 채택한다는 뜻은 아니다.

사용자는 초반 라코코의 실제 사건 비중을 높이고, 중후반 다른 스트리머에게 일어난 가벼운 사건도 각색해 넣으며, 엔딩을 여러 가지로 만드는 방향을 제안했다. 조사 범위를 다음처럼 확장한다.

- **초반**: 라코코 고유 소재로 인사·팬 호칭·기본 콘텐츠·반응을 익힌다.
- **중반**: 다른 스트리머 사례에서 추출한 방송 공통 상황을, 준비·장비·연습·합방 조건에 맞게 등장시킨다.
- **후반**: 이전 선택의 후속 사건을 중심에 두고 조건을 충족한 특별 콘텐츠를 섞는다. 새 카드만 추가해 길이를 늘리지 않는다.
- **엔딩**: 게임 도전·팬 소통·콘텐츠 기획·합방 등 누적 기록에서 대표 결말과 세부 회고를 조합한다.

타 스트리머는 최소 20명을 넘겨 조사할 예정이며, 아직 이 수량을 조사 완료했다는 뜻은 아니다. 사건마다 원래 인물·원출처·검증 상태를 보존하고, 라코코에게 실제로 일어난 일처럼 기록하지 않는다. 사건 유형 중복, 지나치게 진지한 사건, 사생활·오컬트 소재는 제외한다.
