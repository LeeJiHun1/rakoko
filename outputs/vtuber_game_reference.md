# 참고 게임: 버튜버로 살아가기

조사일 2026-11-03 · [플레이 사이트](https://vtuber-game.bigburryong-portfolio.workers.dev/)

## 관찰 범위

새 인생을 시작해 실제 선택지를 고르고 상점을 열어 가상 장비를 구매했다. UI로 확인한 사실과 설명만 확인한 기능, 라코코 게임에 대한 제안을 구분한다. 전체 사건·숨은 확률·모든 엔딩은 조사 완료하지 않았다.

추가 플레이 완료: 9세 저장 지점을 이어 15세 첫 방송, 개인 방송 운영, 소속사 경로, 합방 서버와 대회를 거쳐 22세 계약 만료 때 졸업을 선택하고 최종 결산에 도달했다. 관찰한 하나의 종료 경로이며 모든 엔딩을 확인한 것은 아니다.

## 완료한 플레이의 결과

- 결산 칭호: 꾸준한 방송인. 활동 기간 7년, 데뷔 나이 15세, 종료 나이 22세.
- 최고 팔로워 1,746명, 최고 유튜브 구독자 1,060명, 최고 동시 시청자 82명.
- 누적 방송 수익 678만원, 방송 횟수 1,262회, 대회 2회 출전·우승 0회로 표시됐다.
- 합방·서버·대회, 공약 설정과 실패 회수, 커버곡 제작, 마이크·아바타 구매, 기념 방송, 통계·반응 메뉴를 확인했다.
- 개인 방송에서 소속사 활동으로 옮기며 다른 캐릭터가 되는 경로도 플레이했지만, 사용자가 민감하다고 지적한 뒤 **우리 게임에서 해당 구조를 제외**하도록 문서에 반영했다.
- 종료는 메뉴의 저장 삭제나 강제 새 게임이 아니라, 계약 만료 때 제시된 졸업 선택→졸업 방송→인생 결산 순서로 진행했다. 실제 라코코의 은퇴·계약 사건을 제안하는 뜻이 아니다.

결산 화면: `vtuber_playthrough_ending.jpg`. 라코코 팬게임의 독자적 규칙은 `rakoko_original_game_direction.md`, 종료 후 시작한 외부 수집은 `rakoko_external_candidates.md`에 정리했다.

## 방송 이후 직접 확인한 구조

| 요소 | 직접 관찰 | 수집에 필요한 자료 |
|---|---|---|
| 운영 방침 | 방송 강도·주력 콘텐츠·채팅 규칙·기념일 방침 | 기본 방송 루틴과 진행 방식 변경 |
| 수익화 해금 | 팔로워·방송 시간·누적 시청자 조건을 충족해 구독 활성화 | 공개된 단계 달성과 반응. 실제 플랫폼 규칙은 별도 검증 |
| 개별 방송 장면 | 첫 방송·생일·합방·서버·대회가 LIVE 화면과 결과를 가짐 | 도입·중간 해프닝·마무리 반응 |
| 지연 사건 | 서버 신청→심사→개장→추가 합방→종료, 공약→기한 후 회수 | 여러 날짜의 선행/후속 근거 |
| 능동 콘텐츠 | 커버곡 제작에 게임 자금 사용, 장비와 아바타 업그레이드 | 준비 자료·연습·제작 과정과 결과 |
| 관계에서 생긴 기회 | 서버에서 만난 상대가 나중에 합방 제안 | 공개 협업의 연결. 사적 친밀도 추정은 제외 |
| 능동 주최 | 대회·합방 서버 메뉴에 예산·준비 기간·참가 규모 | 행사 준비·역할·진행 기록. 자금 부족으로 실제 주최는 못 함 |
| 실패의 다른 성과 | 예선 탈락에도 협업·노출 기록이 남음 | 승패 외 배운 점·후기·다음 약속 |
| 결산 | 칭호와 채널 최고치·활동·참가 기록·함께한 인물 | 플레이 회고 태그와 사건 연결 |

실제 플랫폼 규정이나 개인의 의학적 상태를 검증한 자료로 게임 설정을 인용하지 않는다. 신의상·굿즈의 모든 선택지, 직접 주최 결과, 최상위 성장·장기 경력 엔딩은 미확인이다.

## 직접 확인한 요소

- 출생 조건에는 지역·가정 환경·성격·재능·건강 등이 있다. 생성된 가상 인물의 이름은 기본값으로 사용했다.
- 월 단위 진행, 배속 최대 4배, 일시정지와 자동 저장 안내가 있다. 선택 창·상점·메뉴가 진행 화면과 분리되어 있다.
- 상태는 체력·멘탈·스트레스, 능력은 토크·노래·게임·창작·매력·기술·사회성·학업으로 나뉜다.
- 출생 후 선택은 능력과 자원을 바꾸며, 결과와 수치 설명이 기록에 남는다.
- 상점에서 가상 자금 25만원으로 웹캠을 실제 구매했다. 잔액 0원, 보유 장비 변경, 상위 트래킹 장비의 다음 구매 후보를 확인했다. 기술 수치도 1에서 3으로 표시되었으나 방송 사고 감소율을 실측한 것은 아니다.
- 장비 설명은 방송 품질과 사고 감소에 연결된다고 안내한다. 돈이 부족한 항목은 선택할 수 없었다.
- 방송 시작 전 화면은 방송을 시작하면 채널 이름·팔로워·구독자·시청자 지표가 나타나고 방송 강도·주력 콘텐츠를 정할 수 있다고 안내한다. 구체적인 성장 공식은 이 안내만으로 확정하지 않는다.

## 두 참고 게임의 역할

| 비교 축 | 80억분의 1에서 참고 | 이 게임에서 참고 | 라코코 게임 방향〔제안〕 |
|---|---|---|---|
| 긴 흐름 | 시간·평소 초점·사건·지속 상태·결산 | 방송 성장에 맞춘 상태와 능력 | 한 시즌 방송일지 |
| 능동 관리 | 소비·훈련·정책·예약 사건 | 방송 장비의 단계별 구매 | 장비·자료·연습 준비 |
| 측정 결과 | 생애 기록과 여러 축의 회고 | 방송 전용 채널 지표 | 도전·팬 소통·기획·합방의 누적 흔적 |
| 주인공 | 임의의 가상 인물 | 임의의 버튜버 지망생 | 공개 방송 캐릭터로서의 라코코 |

라코코 게임은 데뷔 준비나 첫 방송 시점부터 시작하는 것이 어울린다. 유년기·가족 형편·개인 건강을 임의로 생성해 실제 라코코의 삶처럼 제시하지 않는다. 가정·재산·실제 성격을 조사할 필요도 없다.

## 가져올 요소와 조정할 요소

사용자 확정 제외: 타 캐릭터로 환생·재데뷔하는 구조는 민감하므로 채택하지 않는다. 라코코는 같은 주인공으로 유지한다. 이 참고 게임의 경로를 관찰하는 것과 우리 게임에 적용하는 것을 구분한다.

1. **방송 전용 능력과 자원**: 서로 다른 콘텐츠에서 어떤 준비와 숙련이 필요한지 보여주는 구조를 참고한다. 토크·노래·게임을 모두 실제 인물의 점수로 평가할 필요는 없다. 게임 내부 성장값으로 명시한다.
2. **장비의 단계**: 구매 자체보다 어떤 콘텐츠를 열고 어떤 문제의 수습 경로를 늘리는지에 의미를 둔다. 값비싼 장비가 모든 사건을 지우거나 자동 승리시키지 않도록 조정한다.
3. **운영 방침**: 콘텐츠 중심 운영과 팬 소통 중심 운영 등 선택의 장단점을 드러낸다. 실제 방송 강도나 건강을 추정해 수치로 만들지 않는다.
4. **여러 채널 지표**: 팔로워·구독자·시청자를 구분하는 아이디어를 참고하되, 첫 버전은 필요한 지표만 사용한다. 실제 성장 기록과 가상 플레이 결과를 섞지 않는다.
5. **단계별 사건 풀**: 초반은 라코코 고유 사건, 중반은 타 스트리머 사례를 각색한 공통 사건, 후반은 이전 선택의 후속 사건을 강화한다.
6. **다중 엔딩**: 규모뿐 아니라 도전 완주·팬 소통·새 콘텐츠·합방 등 여러 경로의 성과를 인정한다. 심각한 논란·건강 위기·파국을 엔딩 재료로 넣지 않는다.

## 추가할 수집 필드

- 콘텐츠별 필요한 준비·장비·협업 역할과 실제 사용 장면.
- 장비나 설정 문제를 발견하고 대처한 순서, 원인이 확인됐는지 여부.
- 콘텐츠 강도를 조정하거나 쉬운 코너로 전환하는 공개 진행 맥락.
- 채널 지표의 종류·기준 날짜·화면 근거. 서로 다른 플랫폼 숫자를 합산하지 않음.
- 첫 시도→연습→재도전→다음 콘텐츠 제안까지 이어지는 근거 ID.
- 타 스트리머 사건의 원주인공·원출처·검증 단계·각색 후 남기는 구조·라코코에게 맞지 않는 요소.

기본 조사 원칙은 기존 `rakoko_game_data_plan.md`와 동일하다. 장비 가격·선택 가중치·능력 변화량은 조사 사실과 분리해 플레이테스트로 정한다.
