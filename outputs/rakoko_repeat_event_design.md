# 상태에 맞는 일반 사건과 재등장

2026-11-04 · v1.0. 사용자 요청: 엔딩을 단순 랜덤 조우로 끝내지 않고, 반복 가능한 일반 사건은 여러 번 진행한다.

## 적용 데이터

[일반 사건 연결표](rakoko_event_play_rules.md)와 [JSON](rakoko_event_play_rules.design.json)은 기존 105참조의 312선택을 연결한다. 조사 원문과 선택 문구는 유지하며, 원래의 코너·날짜·약속·의상·기획 조건 위에 선택 수치 제한과 반복 정책을 더한다. 105참조는 일반 추첨 후보 105개가 아니다.

예를 들어 ‘새 전략을 시험한다’는 해당 게임 숙련도 40, ‘정식 코너로 키운다’는 기획력 45·단골층 35, ‘자료 두 버전을 목차로 합친다’는 기획력 35를 요구한다. 시험 소리 내기·간단한 연결 점검·인사·보류·공개 의상 무료 환복에는 불필요한 능력 제한을 붙이지 않는다. 각 일반 사건에 최소 하나의 수치 제한 없는 선택을 남긴다. 원래의 해금·준비·대상 존재 조건은 그대로 검사한다.

상황 없는 무작위 사건을 만들지 않는다. 게임 업데이트는 실제로 그 게임을 편성한 때, 팬 작품 감상은 소개할 창작물이 준비된 때, 합동 방송 화면 문제는 합동 기획 중에만 후보가 된다. 지금의 한국어 조건을 정식 predicate로 변환해야 실제 엔진에 적용할 수 있다. 자동으로 문자열을 해석하지 않는다.

상태에 따른 상대 등장 가중치도 데이터로 둔다. 운영력 60 이상이면 일반 장비 오류의 상대 가중치 0.6배, 숙련도 60 이상이면 기초 복습 사건 0.4배, 숙련도 40 이상이면 새 전략·기록 도전 같은 심화 사건 1.3배, 단골층 50 이상이면 참여형 투표·기획의 상대 가중치 1.3배를 기본안으로 쓴다. 원래 상황 조건을 통과한 사건끼리만 적용한다. 게임 값은 편성한 게임에 바인딩한다. 능력이 높다고 모든 사고를 제거하거나 특정 성공을 자동 생성하지 않는다.

## 반복 정책

|종류|정책|
|---|---|
|일반 장비 문제·대기·질문·진행 해프닝|반복 허용, 같은 family 최소 방송 간격 5회|
|새 기획·새 리허설·새 성공의 회수|새 context ID에서만, 같은 context 1회, 일반 반복보다 긴 간격 8회|
|편집·파일 정리 같은 방송 후 사건|새 방송 결과물 ID별 1회, 간격 4회|
|약속 후속|원 약속 인스턴스별 1회. 새로운 약속이면 새 인스턴스|
|성공 반응|실제 도전 결과 ID별 1회. 반응 카드가 성공을 만들지 않음|
|기념일·의상 공개|발생 연도/주년/의상 해금 ID별 1회|
|일부 유출|의상별 1회, 기존 규칙 유지|
|구체적인 원자료 각색 RK·RA|같은 일지에서 1회. 비슷한 일상 상황의 재발은 창작 CE로 표현|

일반 추첨 후보 중 창작 55참조에 반복 또는 새 맥락 재등장 정책을 부여했다. 모든 55개가 매번 무조건 적격이라는 뜻은 아니다. 재등장해도 선행 조건과 코너가 맞아야 한다.

최소 간격 5는 방송 1회에 발생했다면 방송 6회부터 다시 가능하다는 뜻이다. 같은 family는 한 방송에서 최대 한 번이며, 같은 group은 발생 방송과 이후 두 방송에서 제외한다. RK·CE가 같은 family면 첫 회차를 공유한다. RK가 먼저 나왔어도 충분한 간격 뒤 창작 CE는 재발할 수 있지만, CE를 먼저 사용한 소재의 RK를 뒤늦게 첫 사건처럼 재생하지 않는다.

반복 사건은 회차별 새 인스턴스를 만들고, 같은 인스턴스의 저장 재개는 새 사건으로 세지 않는다. 최초 인지도·업적·해금·한 약속의 보상은 중복 지급하지 않는다. 새 방송 코너를 실제 완료한 통상 성장과 실제 새 약속 생성은 허용한다.

현재 반복 소재의 본문은 원안 1개다. 출시 전 반복 소재별 변주 최소 3개를 목표로 한다. 예를 들어 화면 문제는 다른 송출 소스·준비된 대체물·이전 해결 기록을 반영한다. 제목만 바꾸거나 같은 해결 약속을 계속 쌓지 않는다. 똑같은 설정을 고쳤다면 해당 설정은 정상으로 유지하고 다른 원인이 확인된 때만 새 사건을 쓴다. 진행 중인 동일 수습 약속은 다시 생성하지 않고 기존 약속을 참조한다.

## 엔딩과의 경계

반복 일반 사건에서 얻는 것은 상태 변화·경험·기획 준비다. 이들을 쌓아 승인한 마무리 기획의 조건을 채운 뒤 구체적인 종결 선택을 해야 일반 엔딩을 본다. 일반 조우나 반복 횟수만으로 크레딧으로 보내지 않는다. 무엔딩 10년 강제 결혼만 사용자 지정 예외다.

이 정책은 이전의 ‘모든 family는 장당 1회 소진’을 대체한다. 기존 [1년 공급 보고서](rakoko_draw_review.md)는 전부 일회성으로 계산한 과거 비교 자료다. 56.4%를 최신 반복 정책의 필연적인 대체 하한으로 해석하지 않는다. 반복·맥락·수치·실제 선택을 반영한 새 공급 검증이 필요하다. 반복 허용이 새 소재와 후속 제작의 필요를 없애지는 않는다.

연결표의 repeat 정책은 원안 카탈로그에 남아 있는 max_occurrences_per_season: 1보다 우선한다. 그 원안 필드는 이전 초안 이력이다. 원본문구·사실근거는 덮어쓰지 않고 현재 게임 정책을 합성해 사용한다.

장기 콘텐츠64사건은 별도 활성 모듈 풀이다. 진행40개는 단계당1회, 반복24개는 모듈 참여 방송 간격2회 이상이다. 일반 group간격 대신 모듈 전용 규칙을 적용하고, 한 방송 최대2칸·단계전이1회를 지킨다. 일반 반복55참조와 합산해 독립 랜덤 사건 수로 보고하지 않는다.
