# 방송 스테이터스·사건 경험·선택 제한

2026-11-05 · v2.0 · 첫 구현 기본값. 실제 방송 지표의 추정값이나 플레이테스트 결과가 아니다.

## 수치와 범위

|상태|초깃값|범위·보존|뜻|
|---|---:|---|---|
|인지도|10|0~100, 같은 일지 누적|방송이 알려진 정도. 외부 초대·파급 기획의 조건|
|단골 시청층|20|0~100, 같은 일지 누적|함께 참여하는 시청층의 기반. 팬 기획·정기 모임 조건|
|기획력|15|0~100, 같은 일지 누적|기획을 구성하고 작품으로 완성하는 능력|
|방송 운영력|20|0~100, 같은 일지 누적|진행·편성·대체 송출을 다루는 능력|
|게임 숙련도|게임마다 10|게임 ID별 0~100, 같은 일지 누적|해당 게임의 조작·공략·협동 역량. 다른 게임에 이전하지 않음|

한 가지 수치로 모든 선택을 열지 않는다. 인지도는 게임 공략이나 송출 능력을 대신하지 않는다. 단골 시청층은 참가 동의·기획 승인·리허설을 대신하지 않는다. 의상 종류에 성능 차이를 부여하지 않는다. 평균·최고 동시 시청자나 팔로워 표시값은 후속 UI 과제로 두고 첫 버전의 종결 조건에는 직접 쓰지 않는다.

## 성장 기본값

|행동·결과|증가량|
|---|---|
|자료 준비 1행동|기획력 +2|
|게임 연습 1행동|선택한 해당 게임 숙련도 +2|
|화면 점검|운영력 +1. 같은 방송의 두 번째 점검은 추가 수치 없음|
|잡담 코너 완료|단골 시청층 +1|
|게임 코너 완료|그 코너의 게임 숙련도 +1|
|팬 참여 코너 완료|단골 시청층 +1|
|특별 기획 코너 완료|기획력 +1|
|새 독립 소재를 실제 완료|인지도 +1. 동일 family는 같은 일지에서 한 번만|
|명시된 사건 결과 보너스|관련 수치별 최대 +2. 선택 전에 표시|
|의상 제작·무료 환복·재감상·날짜 이동|스테이터스 증가 없음|

수치별 방송당 양의 증가 합계는 +6까지다. 게임 숙련도는 게임별로 제한한다. 코너 보상·준비 보상·사건 보너스를 합산하고 남은 한도만 적용한다. 예를 들어 게임 연습 두 번(+4)과 같은 게임 세 코너(+3)를 마쳐도 +6이다. 나중에 줄어든 수치가 있어도 이미 쓴 양의 증가 한도는 복구하지 않는다. 반복 일상도 실제 새 방송의 코너 완료 성장은 받되 새 독립 소재 인지도와 최초 경험을 중복 지급하지 않는다.

실패했다고 기획력·운영력·게임 숙련도를 자동 차감하지 않는다. 사전에 예고하지 않고 약속을 취소하는 등 분명한 선택에는 단골층 -2를 표시할 수 있으며 방송당 총 감소는 -4까지다. 감소를 선택하지 않아도 계속 진행할 경로를 둔다. 시간 경과에 따른 자동 감소는 없다.

이 수치는 첫 빌드 값이다. +6이 매회 보장된다는 뜻이 아니며 1년 안의 모든 엔딩 도달을 검증한 값도 아니다. 결과별 보너스와 선행 사건을 실제 데이터에 붙인 뒤 목표 수치 도달 시점을 측정한다.

## 사건 경험의 기록

[엔딩 요구 데이터](rakoko_ending_requirements.design.json)에 EX-001~032를 정의했다. 단순히 사건 화면을 봤다는 것과 지정 결과까지 수행했다는 것을 구분한다. 경험은 해당 결과를 저장한 순간 기록하고 `경험 ID + 원 사건 인스턴스 ID + 결과 ID`로 중복을 막는다. 업적 달성에서 경험을 역생성하지 않는다.

경험에는 방송 ID·날짜·기획 ID·해당 게임 ID를 보관한다. 경험 보유는 같은 일지 누적이다. 현재 기획의 리허설 상태는 현재 기획에만 유효하며 다른 기획의 상태를 복사하지 않는다. 게임 경험(EX-003·004·005·014)은 현재 엔딩 기획의 게임 ID와 일치하는 기록만 사용한다.

예: 다른 게임에서 EX-003을 얻었더라도 현재 게임의 고난도 공략 검증 경험은 없는 상태다. 같은 게임이라도 현재 기획의 마지막 루트 리허설을 안 했다면 준비 조건이 부족하다.

## 보이는 선택과 누를 수 있는 선택

**선택 표시 → 실행 가능 판정 → 클릭 시 재검증**을 구분한다. 이 규칙은 일반 사건·후속·엔딩 선택에 공통으로 적용한다. 사건에서 선택 문구를 보여주더라도 수치·경험·준비·비용 조건이 하나라도 부족하면 선택 버튼을 비활성화한다. 키보드나 직접 명령으로도 실행할 수 없어야 한다.

- 잠금 이유에 `운영력 52 / 필요 60`, `음성 시험 방송 경험 없음`, `현재 특집의 리허설 미완료`처럼 부족한 항목을 모두 표시한다.
- ‘음성 편성으로 수습’은 운영력과 음성 시험 경험, ‘작품 연재로 전환’은 기획력과 파일럿 경험을 요구한다. 관련 없는 인지도만으로 기술 선택을 막지 않는다.
- 일반 선택 기준은 일상 0~20, 중급 기획 30~50, 전문 기획 55~70을 참고한다. 모든 선택에 한계값을 붙이지 않고 역량이 실제 필요한 선택에만 붙인다.
- 조건을 통과했다고 수치를 소모하지 않는다. 비용은 별도 항목이다. 확인창에서 조건이 나빠졌다면 실행하지 않고 최신 잠금 이유를 표시한다.
- 선택을 기다리는 동안 날짜·성장 행동을 진행하지 않는다. 부족한 능력을 같은 사건 화면에서 반복 훈련해 잠금을 우회하지 않는다. 다음 방송으로 돌아가는 안전한 선택을 남긴다.
- 일반 엔딩 사건은 경험·준비가 맞으면 수치가 모자라도 등장할 수 있다. 그 경우 해당 종결 선택은 잠겨 있고 계속 방송을 선택할 수 있다. 사건마다 따로 굴려 등장률을 늘리지 않는다.

## 엔딩 연결과 예외

32개 일반 결말에는 각각 2개의 관련 스테이터스 기준, 특정 EX 경험, 현재 기획 준비 조건을 연결했다. 모든 조건은 AND다. [분기 목록](rakoko_ending_routes.md)에서 각 결말의 실제 수치를 확인한다.

예를 들어 ‘화면이 꺼져도 들리는 방송’은 **운영력 60·단골층 35**, **음성 시험 방송 경험**, **현재 특집의 음성 대체 리허설**, **최종 특집 화면 정지 상황**이 함께 있어야 해당 선택을 누를 수 있다. ‘더 큰 편성표의 한 칸’은 **인지도 65·운영력 60**, **외부 특집 약속 이행 경험**, **일정 충돌 상황과 대체 진행 합의**를 요구한다.

엔딩을 한 번도 보지 않고 방송 10년에 도달하면 **END-FORCED-10Y: 10년의 방송, 둘의 엔딩**을 강제 적용한다. 가상의 키몽이 NPC 한 명과 결혼하는 종결이며 일반 선택의 수치·경험 제한을 적용하지 않는다. 이것은 사용자 지정의 명시적 예외다.

## 조건 데이터와 이관

조건 연산은 `all/any`, `eq`, `gte`를 사용한다. 경로는 stats·experienceCounts·experienceCountsByGame·story 및 별도 자원 economy.cash의 허용 키에 한정한다. 경로가 없거나 타입이 틀리면 미충족이다. 게임 경로의 `$game`은 현재 기획의 gameId로 바인딩하고 gameId가 없으면 미충족이다. 게임 한정 경험은 experienceCountsByGame.$game.EX-ID로 조회하고 기록에서 현재 gameId에 맞게 필터한다. 일반 경험은 experienceCounts.EX-ID로 조회한다. 원문 문자열 비교나 임의 코드를 실행하지 않는다.

보상·성장·경험·기획 상태·선택 결과를 같은 저장 트랜잭션에 적용한다. 수치와 경험은 장 전환 시 보존하며 별도 새 게임에서만 초기화한다. 구버전 세이브는 원본을 백업한 뒤 시작 수치를 채우고, 증거가 있는 기존 결과 이력만 경험으로 이관한다. 기록이 없는 경험은 보유로 가정하지 않는다. 선행 콘텐츠 생산자가 미연결된 EX는 해당 특수 엔딩의 완성 항목으로 세지 않는다.

[일반 선택 연결표](rakoko_event_play_rules.md)에 전체105참조·312선택을 연결했다. 일반 엔딩은 승인한 마무리 기획만 기회가 생기며 조건을 채운 뒤 예약할 수도 있다. 일반조우만으로 종료하지 않는다.

장기 콘텐츠의 게임 숙련도는 moduleInstance.gameId를 사용한다. 서버 지역 자원·직업·팀 호흡은 전역 수치와 구분하고, 참가·지원·시점 소개를 우승 경험으로 세지 않는다. 경험 생산6종의 결과 조건은 rakoko_long_content_bridges.design.json을 따른다.


## 보유 자산 리소스 추가

보유 자산은 economy.cash를 스테이터스 패널에 함께 표시한다. 초기3,000,000원이며 능력치0~100이나 방송당+6 한도를 적용하지 않는다. 방송3칸 완료 후 인지도/단골층의 시작값으로 수입을 계산하고 기본 운영비30,000원을 함께 정산한다. 초기 순수입은270,000원이다.

잔액 부족 시 유료 선택은 표시하되 비활성화하고 해당 이벤트를 포기한다. 무료로 같은 유료 작업을 완료하거나 지출을 미루어 빚으로 만들지 않는다. 원래 능력 조건은 돈으로 면제되지 않는다. 의상 준비500,000원/행동+25와 공개 의상 무료 환복, 원자 거래·구매·대회 상금은 [경제 설계](rakoko_economy_design.md)를 따른다.

경제v2.0은 min(인지도,단골층)의 규모 단계와 최고해금배율을 사용한다. 0~100 역량과 현금자산은 계속 별도이며 상세 수입·운영비·지출은 경제원본을 참조한다.
