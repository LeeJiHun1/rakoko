# 보유 자산·방송 수입·지출 설계

2026-11-05 · v2.0. 사용자 요청: 보유 자산을 표시하고 방송으로 돈을 벌며, 유료 사건은 지출한다. 잔액 부족 시 해당 사건을 포기한다.

## 자산의 정의와 초깃값

보유 자산은 현재 사용할 수 있는 **방송 자금**으로 정의한다. 새 게임은 **3,000,000원**에서 시작한다. 게임 밸런스를 위한 가상 원화이며 실제 라코코의 자산·후원·수입·제품 가격을 추정한 값이 아니다.

저장 원본은 `economy.cash` 하나다. 스테이터스 패널에서 이를 읽어 보유 자산으로 표시한다. 기존 능력 수치0~100 및 방송당 성장+6 제한을 적용하지 않는다. 정수0~9조 범위로 검증하고 음수나 자동 대출을 만들지 않는다. 같은 일지의 새 장에서는 자금을 유지하고 별도 새 게임만 초기화한다.

서버 속 생활 자원·거래 화폐·직업 경험은 모듈 지역 상태다. GTA형 서버 안에서 돈을 벌거나 마크형 서버에서 재료를 거래했다고 방송 자산이 증가하지 않는다. 게임 방송을 마친 수입과 실제로 확인된 가상 대회 상금은 방송 자금에 반영한다.

## 방송 수입과 정산

공개 가격·수익 구조 조사와 게임 값의 구분은 [경제 규모 조사](rakoko_economy_research.md)에 기록한다. 방송 규모를5단계로 나누며 기본 정산은 다음과 같다. 수치는 방송 시작 시 고정한다.

`기초총수입 = 50,000 + 인지도×2,000 + 단골층×2,000 + 완료코너×30,000 + 세코너완료보너스100,000`

`최종총수입 = 기초총수입×규모배율`, `운영비 = 30,000×규모배율`, `순수입 = 최종총수입−운영비`

|단계|해금 성장지표|배율|인지도/단골층 예시|3코너 순수입|
|---|---:|---:|---|---:|
|시작|0|1|10/20|270,000원|
|성장|25|2|30/35|680,000원|
|중견|45|5|50/55|2,100,000원|
|대형|65|12|70/75|6,000,000원|
|최상위|85|25|90/95|14,500,000원|

성장지표는 min(인지도, 단골층)이다. 현재 수치로 해금한 단계와 기존 최고 해금 단계 중 높은 것을 방송 시작 시 저장한다. 단골층이 잠깐 감소했다고 배율을 강등하지 않는다. 같은 일지에서 최고 단계를 보존한다. 인지도/단골층100/100은 총16,000,000·운영비750,000·순15,250,000원이다. 현실의 회당 평균 수입이나 실제 플랫폼 정산액을 뜻하지 않는다.

정상 방송은3칸을 마친 뒤 일지 확정과 일반 엔딩 검사 전에 수입·운영비를 한 거래로 정산한다. 잔액0원이어도 운영비를 선납하지 않고 방송을 시작해 자금을 모을 수 있다. 아무 코너도 완료하지 않으면 수입·운영비0원이다. 앱 종료는 정산이 아니며 진행을 보존한다. 중도 종료 기능을 만들 경우 실제 완료 코너만 계산하고3칸 보너스는 주지 않는다.

날짜 건너뛰기·일지/엔딩 재감상·무료 환복·대표 장면 변경은 수입을 만들지 않는다. 구매 창을 닫은 횟수도 코너 수입으로 세지 않는다. 첫 정산 후 다시 열어 돈을 받지 않는다. 실제 구독·광고·후원 수수료를 별도로 중복 차감하지 않고 게임용 공식에 압축한다.

## 돈을 쓰는 선택과 포기

1. 선택 화면에 현재 자산, 지출액, 결제 후 잔액과 구매 범위를 표시한다.
2. 수치·사건 경험·현재 준비·참가 자격과 별개로 현재 잔액을 검사한다.
3. 잔액이 비용 미만이면 유료 선택은 비활성화하고 `현재100,000 / 필요500,000원`처럼 이유를 표시한다.
4. 잔액과 조건을 충족하면 확정 시 한 번 차감하고 구매/의뢰 접수·원 사건 결과와 함께 저장한다.
5. 돈이 없거나 원하지 않으면 **이번 이벤트 포기**를 고른다. 지출·구매·유료 작업 진행도·보상·성공 경험은 없다.

싼 유료 선택이 따로 있고 그 가격은 감당할 수 있다면 축소 범위로 진행할 수 있다. 포기는 같은 결과를 무료로 얻는 경로가 아니다. 빚을 내거나 잔액을0으로 잘라서 강제로 결제하지 않는다. 방송에서 나중에 받을 예상 수입을 먼저 쓸 수 없다.

포기한 유료 사건은 현재 요청을 취소하고 일반 방송으로 돌아간다. 자동으로 매 방송 재제안하지 않고 플레이어가 다시 요청하거나 새 기획이 생겼을 때만 새로 제안한다. 포기만으로 단골층·기획력·약속 위반 벌점을 주거나 큰 손실·게임오버를 만들지 않는다. 이미 별도 이행 중인 약속을 취소할 때는 원 약속의 변경/보류/취소 규칙을 따로 보여준다.

## 지출 사건과 기존 콘텐츠 연결

[유료 사건16종·48선택](rakoko_money_events.md)을 추가했다. 새 게임·추가 콘텐츠, 장비 수리/대여, 추가 녹화 보관, 썸네일·화면 구성·영상 편집 의뢰, 소품·기념품, 행사 공간·전시 에셋·합동 장비를 다룬다. [JSON](rakoko_money_events.design.json)에 가격·요청 맥락·차감·접수·포기 효과를 연결했다.

이 사건은 해당 요청/필요 상태가 있을 때만 후보가 된다. 준비 중 직접 요청하거나 현재 코너의 관련 일반 사건 한 칸을 대체하며 무료 추가 사건으로 슬롯을 늘리지 않는다. 기본값0원인 기존 선택을 실행 중 갑자기 유료로 바꾸지 않는다. 게임 안의 가상 블록·직업·아이템 비용은 원래 지역 자원으로 계산한다.

의뢰료를 지불하면 ‘납품 대기’ 영수증을 얻는다. 납품·적용·검수·리허설이 끝나기 전에는 준비 완료나 EX경험을 자동 지급하지 않는다. 축소 의뢰는 축소 범위만 완료한다. 같은 프로젝트/구매 대상의 영수증은 중복 결제하지 않으며 대여 기간과 구매 소유권은 구분한다. 유료 사건을 포기해도 기본 방송이나 게임 저장을 유료로 막지 않는다.

## 의상 준비 비용

의상 제작 준비 행동1회는 **500,000원 + 준비 행동1회 → 준비도+25**다. 정식 공개까지 기본4행동·총2,000,000원이 필요하다. 준비 화면에서 누적 사용액과 다음 행동 비용을 보여준다.

잔액이 부족하면 제작 행동을 누를 수 없고 이번 준비를 건너뛰거나 다른 행동을 한다. 돈·준비 행동·진행도가 일부만 적용되지 않는다. 이전에 지불하고 쌓은 진행도는 그대로 보존한다. 소비한 준비비와 행동은 중단·대상 변경·포기 시 환급하지 않는다.

준비비는 게임 내 방송 기획 비용이며 실제 의상/원화 제작료가 아니다. 유출로 조기 공개하면 이미 지불한 비용은 유지하고 이후의 준비 행동과 비용만 필요 없어질 수 있다. 정식/조기 공개의 해금 자체에 추가 요금은 없다. **공개한 옷의 준비·방송 중 환복은 계속0원·행동0회**다. 재감상이나 환복으로 돈을 벌지 않는다.

## 대회 보상과 특별 종결

가상 플랫폼 대회 우승 보상은5,000,000원, 스트리머 친선전 우승 보상은2,000,000원을 기본값으로 둔다. 가상의 개인 지급 몫이며 팀 전체 상금을 혼자 받는 금액이 아니다. 실제 대회의 상금 수치가 아니다. 본선 참가 확정·선수 역할·실제2승·대회 완료가 모두 확인된 경우에만 competitionInstanceId별 한 번 지급한다. 교육전·진행 보조·상대 구경·참가만으로 상금은 없다. 일반 방송 수입과 우승 상금은 서로 다른 거래 ID로 기록한다.

일반 엔딩의 기존 스테이터스·경험·준비 조건은 돈으로 대체하지 않는다. 유료 마무리 작업이 있다면 지출부터 실제 납품·준비 완료까지 수행해야 한다. 잔액 부족으로 포기하면 그 기획은 종료되지 않고 일반 방송으로 자금을 모을 수 있다.

무엔딩10년 강제 결혼은 비용0원이다. 자산이 없다고 잠그거나 자동 대출하지 않고 지정된 종결을 적용한다. 유료 이벤트·모듈 지역 상태·미납 구매 요청이 강제 엔딩을 늦추지 않는다.

## 거래·저장과 오류 복구

트랜잭션 ID는 원인이 정해지면 고정한다. 방송 정산은 `runId + broadcastId + incomeSettlement`, 유료 선택은 `eventInstanceId + choiceId + effectIndex`, 우승 상금은 `competitionInstanceId + winnerPrize`를 사용한다. 새로고침·더블클릭·오래된 탭·결제 후 연출 재생은 같은 거래를 재적용하지 않는다.

처리는 최신 revision/수치/경험/잔액 재검증 → 거래·자금·구매/진행·처리 명령·일지의 원자 저장 → 화면 표시 순이다. 결제 검증 실패는 잔액과 사건을 유지하고 포기 선택으로 돌아갈 수 있게 한다. 저장 실패 시 성공 결과나 새 잔액으로 진행하지 않는다. 장부와 잔액이 맞지 않으면 임의 보정 대신 직전 정상 저장을 복구한다.

장부에는 거래ID·방송/사건/선택·수입/운영비/준비비/구매/상금 구분·증감액·거래 후 잔액·게임 날짜·규칙 버전을 남긴다. 시작 자산도 개시 거래로 기록한다. 구버전 저장에 자산이 없으면 원본을 보관한 뒤 초기 자산을 한 번 부여한다. 이미 자산과 장부가 있는 저장은 임의로10배 하지 않는다. 지난 방송 수입·구매는 소급 재계산하지 않고 진행 중 선택의 저장 가격을 지킨다. 새 가격은 새 요청·새 준비 행동부터 적용한다.

## 검증 기준

- 초깃값3,000,000원, 정상 첫 방송 순수입270,000원, 그 뒤80,000원 구매 시 잔액3,190,000원.
- 비용500,000원에 잔액499,999원은 잠금·포기 가능, 정확히500,000원은 결제 후0원.
- 포기는 자금·구매·진행·성공 경험을 바꾸지 않는다. 결제 실패도 행동 횟수와 진행도를 소비하지 않는다.
- 방송 정산·의상 준비·대회 상금·구매를 같은 ID로 재전송해도 각각 한 번만 적용한다.
- 잔액0원 기본 방송 가능, 앱 종료/재감상/날짜 도약의 수입·자동 고정비 없음.
- 같은 게임 서버의 지역 돈과 방송 자산이 섞이지 않고, 지원 역할은 우승 상금을 얻지 않는다.
- 유출 조기 공개·무료 환복·강제 결혼 비용과 이전 사용자 확정 동작을 지킨다.

수치와 사건 효과는 첫 구현 기본값이며 실행 게임의 경제 밸런스 검증은 남아 있다.

구매/포기 창 자체는 방송 완료 코너 수로 세지 않는다. 방송 중 요청을 포기하면 해당 유료 작업을 완료하지 않고 준비된 다른 콘텐츠로 돌아가며, 실제 콘텐츠를 마친 코너만 정산에 포함한다. 구매 창을 열고 포기하는 반복으로 방송 수입을 만들지 않는다. 포기는 결제 전 선택이며 이미 결제한 별도 구매 영수증이나 기존 의상 진행도를 되돌리지 않는다.

v2.0은 초기 자산과 회당 수입의 규모를 올리고, 소액 게임 구매와 제작·행사 예산의 차이를 넓혔다. 새 대형 지출은 작업실1,500만원·온라인공연3,000만원·직접주최대회5,000만원·팬행사8,000만원(각 축소안 있음)이다. 비용을 지불해도 납품과 실행·검증 전에는 준비/경험을 자동으로 얻지 않는다.
