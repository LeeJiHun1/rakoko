# 라코코의 방송일지 — 판단 가이드

## 1. 범위와 원칙

판단은 방송 중 공개적으로 나타난 행동과 발언을 대상으로 한다. 실제 인물의 내면·성격·의학적 상태를 추정하는 문서가 아니다. 사건의 결과가 선택의 의도를 증명하지도 않는다.

근거 등급은 말투 가이드와 동일하다. A는 원본 음성·화면·화자 대조, B는 자동자막 문맥 검토, C는 제목·외부 기록이다. 현재 A 근거는 0건이다. **아래 게임 규칙은 제안이지 라코코의 실제 행동을 예측하는 확정 모델이 아니다.**

기획 확정 조건: 오컬트 제외. 라코코를 주인공으로 한 선택·확률형 방송일지. 사건 선택의 폭은 플레이어에게 남긴다. 실제 방송과 다른 경로도 허용하되 창작 분기로 표시한다.

## 2. 판단 카드

### D01. 기술 문제가 생기면 설명하면서 복구를 시도

- 자극: 방송 장면·설정이 의도대로 작동하지 않음.
- 관찰: [1월 18일 00:12:00–00:16:20](https://www.youtube.com/watch?v=Kv03yHk6Fe8&t=720s)에서 카메라 설정 문제를 언급하고 진행이 끊김. [1월 22일 00:05:50–00:06:50 및 00:25:20–00:26:50](https://www.youtube.com/watch?v=-KemMFgrOII&t=350s)에서는 구독·후원 설정을 방송 중 조정하는 흐름.
- 잠정 해석: 문제가 생기면 바로 방송을 포기하기보다 수습하며 계속하려는 사례가 있다.
- 대안 해석: 데뷔·초기 설정이라는 특별한 상황일 수 있음. 모든 기술 문제에 대한 보편 반응은 아님.
- 게임 적용: 즉시 고치기 / 임시 화면으로 전환 / 다른 콘텐츠로 대체. 복구 성공 여부는 준비도와 시간 소모를 함께 반영.
- 근거: B, 여러 날의 사례. 확신도 중간.

### D02. 늦은 상황에서 사과와 경위 설명을 함께 사용

- 관찰: [5월 10일 00:02:20–00:03:30](https://www.youtube.com/watch?v=28oEgK4mT-o&t=140s), [10월 5일 00:03:10–00:07:10](https://www.youtube.com/watch?v=pjLUfFY0pG4&t=190s).
- 잠정 해석: 책임 인정과 상황 설명을 동시에 할 수 있음. 한 번의 장난을 전부 진지한 갈등으로 읽지 않는다.
- 게임 적용: 사과로 분위기를 안정시킨 뒤 설명하기 / 짧게 설명 후 진행 / 일정 다시 공지. ‘변명 vs 사과’의 이분법을 피한다.
- 미확인: 제안된 벌칙의 최종 수락 여부와 실제 이행.
- 근거: B. 확신도 중간.

### D03. 콘텐츠의 신선함과 시청자의 기대를 고려

- 관찰: [7월 11일 01:41:10–01:42:35](https://www.youtube.com/watch?v=Sd9Oc8NZvb8&t=6070s)에서 업로드할 소재와 방송을 찾아올 때의 기대를 이야기하며 콘텐츠를 만들 필요성을 설명.
- 잠정 해석: 단순히 방송 시간을 채우는 것 외에 소재 확보와 다음 방송의 기대를 고려하는 순간이 있음.
- 게임 적용: 저챗의 즉시 만족과 새 콘텐츠 준비의 장기 가치를 서로 다른 지표로 둔다. 준비를 하면 다음 날 사건 선택지가 늘어나도록 한다.
- 반례 탐색: 실제로 준비를 포기하고 휴식을 택한 날, 저챗만으로 만족한다고 한 장면.
- 근거: B, 현재는 단일 핵심 장면. 확신도 중간 이하.

### D04. 하고 싶은 일을 이루는 가치를 직접 설명한 사례

- 관찰: [6월 11일 00:44:15–00:45:10](https://www.youtube.com/watch?v=ix7-CJW3Mjc&t=2655s)에서 경제적 조건을 가정한 질문에, 원하는 일을 이루는 가치와 돈의 필요를 구분해 설명하는 문맥.
- 잠정 해석: 돈만을 유일한 목적이라고 쓰면 이 발언과 어긋날 수 있음.
- 한계: 가정형 질문에 대한 답변이지 실제 계약·직업 결정을 관찰한 자료는 아니다.
- 게임 적용: 수입, 만족감, 콘텐츠 성취를 분리. 가장 수입이 큰 선택이 유일한 정답이 되지 않도록 한다.
- 근거: B. 확신도 중간 이하.

### D05. 행사에서 수요 예측이 틀리면 대응과 형평성을 고려

- 관찰: [10월 17일 00:02:00–00:04:50](https://www.youtube.com/watch?v=t3Y8PL9bSjk&t=120s)에 준비 물량, 방문 규모, 대응 및 형평성을 이야기하는 흐름이 나타남.
- 외부 맥락: [대전콘텐츠페어 공식 사이트](https://www.dcfair.co.kr/)가 10월 16~18일 행사와 라코코 팬미팅 프로그램을 안내.
- 잠정 해석: ‘더 주면 해결’만이 아니라 이미 참여한 사람과 이후 참여자의 조건도 고려하는 사례.
- 미확인: 정확한 물품명·수량, 화자, 최종 조치. 자동자막의 숫자를 확정하지 않는다.
- 게임 적용: 재고 / 방문 수요 / 공정성 / 준비 시간. 사전 예약, 추가 준비, 균등 배분의 선택.
- 근거: B+C. 확신도 중간 이하.

### D06. 게임 도전에서는 재시도 의지가 드러난 사례

- 관찰: [10월 10일 2부 08:00:30–08:05:00](https://www.youtube.com/watch?v=k4H4epY3pxo&t=28830s)에서 재도전과 목표 유지의 흐름. [08:11:35–08:12:25](https://www.youtube.com/watch?v=k4H4epY3pxo&t=29495s)에서 처치 성공을 말하는 반응.
- 외부 탐색: [클리어를 언급한 커뮤니티 글](https://gall.dcinside.com/mini/board/view/?id=virtual_streamer&no=2487270).
- 잠정 해석: 특정 도전에서 실패 후에도 목표를 계속 추구한 사례. 항상 포기를 못 하는 성격으로 일반화하지 않는다.
- 게임 적용: 재도전은 숙련을 늘리지만 피로와 일정 지연을 동반. 휴식 후 재도전이나 다음 날 이어하기도 유효한 선택.
- 근거: B+C. 화면의 보스 처치 표시와 실제 시도 횟수는 미검증.

### D07. 장난에 대한 거절을 실제 선택으로 보존

- 게임 적용: 요청 거절 후 정상적으로 다음 콘텐츠에 진행할 수 있어야 한다. 거절을 반복해도 반드시 강요되는 분기는 만들지 않는다.
- 근거: B. 확신도 중간 이하.

### D08. 선호·비선호를 장르 선택과 연결

- 관찰: [데뷔 방송 00:32:10–00:33:25](https://www.youtube.com/watch?v=Kv03yHk6Fe8&t=1930s)에 싫어하는 것을 소개하는 구간이 있으며 귀신·공포게임 비선호를 설명한다.

- 게임 적용: 공포 콘텐츠를 필수 성공 루트로 두지 않는다. 나중에 해당 게임을 플레이한 기록이 있어도 ‘처음부터 좋아했다’로 바꾸지 않는다.
- 근거: B+U. 발화 정확성은 음성 대조 대기.

## 3. 방송일지의 상태값 제안

수치와 효과는 모두 게임 설계안이다. 실제 방송 데이터에서 통계적으로 추정한 값이 아니다.

| 상태 | 의미 | 연결할 카드 |
|---|---|---|
| 준비도 | 자료·화면·장비를 미리 점검한 정도 | D01, D03 |
| 체력 | 진행·재도전·행사에 쓸 수 있는 여력 | D02, D06 |
| 현재 분위기 | 지금 방송의 반응과 흐름 | D02, D07 |
| 신뢰 | 공지 이행·경계 존중·사후 수습 | D02, D05, D07 |
| 소재 | 다음 방송과 편집에 활용할 사건 | D03 |
| 숙련 | 같은 게임·도구를 다룬 경험 | D01, D06 |
| 예산·재고 | 행사 준비 및 자원 제약 | D05 |

‘수치심’, ‘굴복’ 등을 인물의 핵심 보상 수치로 고정하지 않는다. 현재 자료만으로 사람의 판단을 그런 하나의 축으로 요약할 수 없다.

## 4. 사건 설계 예시 — 창작, 실제 사건 재현 아님

상황: 새 콘텐츠를 시작하려는데 자료 화면이 열리지 않는다.

| 선택 | 단기 결과 | 후속 결과 |
|---|---|---|
| 5분 점검을 선언하고 복구 | 시간 소모, 준비도에 따른 복구 판정 | 고친 설정을 다음 방송에 재사용 |
| 저챗으로 전환 | 즉시 대화는 이어짐, 준비한 소재는 보류 | 내일 추가 준비 또는 재탕 가능 |
| 시청자와 함께 점검 | 참여 기회, 채팅에 진행이 흔들릴 가능성 | 도움받은 설정의 재발 방지 기록 |

정확한 성공 확률은 아직 정하지 않는다. 실제 인물이 특정 선택을 ‘70% 확률로 한다’는 식의 근거 없는 수치를 부여하지 않는다.

## 5. 판정을 보류할 때

다음 중 하나면 인물의 판단 가이드에 편입하지 않는다.

- 도네이션으로 읽힌 의견인지 본인의 의견인지 불명확함.
- 가정형 질문이나 역할극을 실제 행동으로 읽게 됨.
- ‘하지 않겠다’는 발언 뒤 실제 선택을 아직 확인하지 못함.
- 중요한 부정어·숫자·대상이 자동자막에서 손상됨.
- 외부 글이 악의적 편집, 개인 신상·의학적 정보에 의존함.
- 웃음·비명이라는 자막만으로 감정을 확정해야 함.

## 6. 후속 검토

각 카드에 대해 다른 달의 사례 2개와 반례 1개를 우선 찾는다. 1~3월, 4~6월, 7~9월, 10~11월의 상황 차이를 보존한다. 방송 초기의 장비 미숙을 현재의 고정 능력치로 만들지 않는다.

완료 조건: 원본 대조된 행동 카드 12개 이상, 서로 다른 방송일의 근거, 거절·피로·공지 같은 예외 조건, 반례와 미확인 상태 명시. 이 수는 조사 목표이며 현재 달성 수가 아니다.
