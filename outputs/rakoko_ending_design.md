# 엔딩 사건과 장기 진행

2026-11-04 · v3.1 · 사용자 요청: 일반 엔딩은 연수별 확률, 선택은 수치·경험·준비 조건을 검사하며 무엔딩 10년에 강제 결혼 엔딩을 적용한다.

## 등장 판정

주년 축하와 일반 엔딩은 별도다. 단, 엔딩을 보지 않은 채 10주년에 도달하면 아래 강제 엔딩이 우선한다. 생일·주년 방송만으로 게임이나 장을 종료하지 않는다. 엔딩은 방송의 세 코너와 방송 후 사건을 처리한 뒤 마무리 상태를 저장하고 검사한다. 일지는 엔딩 검사와 사건 선택의 결과를 포함해 최종 확정한다. 첫 1주년(2027-01-18)부터 적격이며 첫 1년은 엔딩 없이 진행한다.

|완료한 방송 연수|검사 1회당 엔딩 사건 확률|
|---|---:|
|1년 이상~2년 미만|5%|
|2년 이상~3년 미만|8%|
|3년 이상~4년 미만|11%|
|4년 이상~5년 미만|14%|
|5년 이상~6년 미만|17%|
|6년 이상~7년 미만|20%|
|7년 이상~8년 미만|23%|
|8년 이상~9년 미만|26%|
|9년 이상~10년 미만|29%|
|10년 이상~11년 미만|32%|
|11년 이상|35%|

연수는 방송 횟수가 아니라 시작일로부터 지난 실제 기념일 횟수다. 2027-01-17은 0년, 다음 날은 1년이다. 확률은 `min(35%, 5% + 3% × (완료 연수 - 1))`다. 이 값은 첫 구현용 밸런스 기본값이다.

- 미당첨 뒤에는 게임 날짜로 30일 이상 지난 첫 방송 종료 시 다시 검사한다. 매 방송 검사해서 오래 진행할 여지를 없애는 일을 피한다.
- 날짜를 여러 해 건너뛰면 도착한 날짜의 확률로 한 번만 검사한다. 건너뛴 날짜를 따라 여러 번 추첨하지 않는다.
- 일반 엔딩 사건이 없거나 검사 대기 중이면 계속 진행한다. 엔딩을 한 번도 보지 않은 run은 10년 시점에 강제 엔딩으로 종료한다.
- 당첨하면 현재 기획·준비 상태에 맞는 구체적인 엔딩 사건 한 개를 제시한다. 조건을 갖춘 종결 선택지를 고르면 해당 결말로 이어지고, 계속 선택지를 고르면 일반 진행으로 돌아간다. 사건마다 다른 선택 문구를 사용한다.
- ‘아직 더 방송하기’는 결과를 저장하고 90일 동안 엔딩 검사를 쉰다. 기록·의상·약속·기획 상태를 초기화하지 않는다.
- 종결 선택의 확인창에서 현재 장이 끝난다는 사실을 확인한 뒤 선택을 확정하면 사건·선택·최종 결과·결말과 전체 기록을 스냅샷으로 저장한다. 같은 일지로 계속 방송하거나 별도 새 게임을 시작할 수 있다. 같은 일지의 다음 방송 생성 시 새 장으로 전환하고 엔딩 검사는 365일 동안 쉰다. 방송 연수는 유지한다.

5%는 연간 5%가 아니다. 5%로 12번 독립 검사한다면 그중 한 번 이상 당첨될 확률은 약 46.0%다. 실제 검사 횟수는 선택한 날짜·검사 간격·보류에 따라 달라진다. 확률 상한을 35%로 두므로 당첨이 보장되는 연도는 없다.

## 조건 → 사건 → 선택 → 결말

누적 달성에 따른 결말 해금 목록은 폐기한다. 이전 9개 명칭과 횟수 조건은 [업적](rakoko_achievement_design.md)으로 이동한다. 업적은 엔딩 등장·선택 자격·결말 종류를 결정하지 않는다.

[엔딩 사건 목록](rakoko_ending_routes.md)과 [구조화 데이터](rakoko_ending_routes.design.json)에 **16개 사건·32개 결말**을 작성했다. 각 일반 사건에는 준비 상황에 맞춘 두 종결 선택과 일반 진행으로 돌아가는 계속 선택이 있다. 별도의 강제 엔딩 1종을 합쳐 총 17사건·33결말이다. 단순히 엔딩 제목을 고르는 화면은 제공하지 않는다.

추첨 순서는 다음과 같다.

1. 무엔딩 10년 강제 엔딩부터 검사한다. 아니면 일반 엔딩의 연수·검사 간격을 확인한다.
2. 플레이어가 마무리 기획으로 승인한 현재 기획의 사건 중, 사건 등장 조건과 최소 한 선택의 비수치 선행 조건(경험·준비)을 만족하는 사건을 후보로 만든다. 이 단계에서는 스테이터스 부족을 이유로 사건을 숨기지 않는다. 후보가 없으면 RNG를 쓰지 않고 계속 진행한다.
3. 위 연수별 확률로 엔딩 사건 등장 여부를 한 번 판정한다.
4. 당첨하면 적격 사건에서 가중 추첨한다. EF-001 가중치 0.5, 특정 기획 사건들은 기본 1이다. EF-001도 선택의 수치·경험 조건을 검사하므로 무조건 선택 가능한 기본 결말은 없다. 사건 수만큼 등장 확률을 여러 번 적용하지 않는다.
5. 사건·선택지·바인딩한 게임 ID·검사 결과를 저장한 뒤 표시한다. 두 종결 선택을 보여주고 수치·경험·준비의 모든 조건을 만족한 선택만 활성화한다. 잠긴 선택에는 현재값/요구값과 부족한 경험·준비를 모두 설명한다.
6. 선택 확정 시 수치·경험·준비·비용 조건을 서버 없는 명령 처리 계층에서 다시 검증한다. 종결 선택은 정해진 END ID 한 개, 계속 선택은 다음 일반 방송으로 이어진다. 종결 선택 뒤 추가 성공 주사위는 없다.

예를 들어 최종 특집의 화면이 멈춘 상태에서 EF-009가 등장해도 누구나 같은 결말을 고를 수는 없다. 운영력 60·단골층 35 이상에 음성 시험 방송 경험과 현재 특집의 음성 리허설이 있다면 ‘음성 전용 편성으로 끝내자’ → **화면이 꺼져도 들리는 방송**, 운영력 50·기획력 55 이상에 시험 상영 경험과 현재 특집의 검수한 녹화 대체본이 있다면 ‘상영회를 열자’ → **생방송 대신 첫 상영회**가 된다. 어느 쪽의 경험·준비도 없다면 이 사건은 후보에서 빠진다. 경험·준비는 있지만 수치가 부족하면 사건은 등장할 수 있고 해당 선택은 잠긴다. 생방송 중단 상태에서만 가능한 분기는 해당 사건의 unresolved 상태를 저장하고 일반 마무리 대신 전용 마무리 장면으로 처리한다.

일반 엔딩에 수동 통제 경로를 추가한다. 기획 화면에서 해당 기획을 ‘마무리 기획’으로 승인해야 자연발생 후보가 된다. 이 승인만으로 종료하지 않는다. 원하면 지정을 해제할 수 있다. 조건을 완전히 갖춘 뒤에는 첫 1주년 이후 ‘마지막 특집 예약’으로 특별 기획 한 칸을 잡아 확정적으로 사건을 진행할 수도 있다. 예약은 기존 의상 공개·수락한 기념일을 덮어쓰지 않고 플레이어가 비어 있는 칸이나 바꿀 일반 칸을 고른다.

연수별 확률은 승인된 기획을 마무리할 기회의 자연스러운 도래에만 쓴다. 최종 크레딧은 언제나 현재 장을 마친다는 설명을 읽고 구체적인 종결 선택을 확정한 결과다. 단순 조우·보상·업적·부족한 스테이터스만으로 게임을 끝내지 않는다. 예약 당시 적격이었어도 실행 시 다시 검사하고, 부족하면 잠금 이유와 계속 선택을 제공한다. 10년 무엔딩 강제 결혼은 이 통제 경로의 명시적 예외다.

모든 결말은 **현재 기획이 어떻게 종결됐는지 → 어떤 선택을 했는지 → 이후 방송이 어떤 모습이 되었는지**를 보여준 뒤 크레딧으로 끝난다. ‘업적을 얻었다’는 알림이나 대표 태그만 표시하면 구현 완료로 인정하지 않는다. 다른 결말은 실제 도달 뒤 갤러리에서 재감상한다. 미도달 결말의 전문을 즉시 미리 보여주지 않는다.

## 스테이터스·경험과 결말의 결합

[방송 스테이터스](rakoko_status_design.md)의 인지도·단골 시청층·기획력·방송 운영력·게임별 숙련도를 사용한다. [요구 데이터](rakoko_ending_requirements.design.json)에 일반 결말 32개 각각의 관련 수치 2개와 지정 경험 EX-001~032를 연결했다. 기존 사건 상황·현재 기획 준비 조건에 이 조건들을 AND로 더한다. 게임 경험과 숙련도는 현재 기획의 gameId로 함께 묶는다.

선택 문구가 요구하는 역량에 맞게 제한한다. ‘전체 진행’에는 운영력, ‘공략’에는 해당 게임 숙련도, ‘팬 기획’에는 단골층, ‘작품 완성’에는 기획력을 쓴다. 선택 표시와 실행 권한은 별개다. 수치를 넘었다고 준비나 경험을 면제하지 않으며 경험이 있어도 수치 미달이면 누를 수 없다. 수치는 사용 비용이 아니다.

## 무엔딩 10년 강제 엔딩

**EF-FORCED-10Y → END-FORCED-10Y: 10년의 방송, 둘의 엔딩**을 추가한다. 시작일 2026-01-18에서 만 10년인 **2036-01-18**, 같은 run에서 실제 도달한 엔딩이 하나도 없으면 적용한다. 업적·엔딩 후보·엔딩 사건을 보기만 한 것은 엔딩을 본 것으로 세지 않는다.

게임 속 가상의 키몽이 NPC 한 명을 고정된 게임 시드로 선정하고 서로의 마음을 확인한 결혼식과 후일담으로 끝낸다. 실제 시청자 계정이나 개인정보에서 배우자를 고르지 않는다. 배우자 ID는 화면 표시 전에 한 번 저장하며 재개해도 바뀌지 않는다.

이 경로는 RNG·스테이터스·경험·리허설·유출·주년 선택·일반 엔딩 검사 대기보다 우선한다. 수치 부족으로 잠그거나 90/365일 대기로 피할 수 없다. 계속하기나 결혼 거절 분기는 없고 연출 건너뛰기는 결말을 그대로 확정한다. 크레딧 뒤 해당 run은 종료 상태로 보관하고 일지·도달 결말 보기·별도 새 게임만 제공한다. 일반 엔딩을 이미 보고 같은 일지로 이어온 경우에는 10년 강제 엔딩을 적용하지 않는다.

다음 방송 날짜를 2036-01-18 이후로 고르면 날짜 이동 명령에서 10년 시점에 멈추고 이 엔딩을 먼저 저장한다. 그 이후의 생일·주년·방송은 생성하지 않는다. 읽어온 구버전 저장이 이미 그 날짜를 넘었다면 원본과 날짜는 보존하고 다음 조작 전에 미처리 강제 엔딩을 실행한다. 일반 엔딩을 본 이력이 있으면 이관 시에도 강제하지 않는다.

따라서 표의 10년 32%와 11년 이후 35%는 이미 일반 엔딩을 본 뒤 이어가는 run에서만 사용한다. 무엔딩 첫 진행에서는 10년 강제 엔딩이 먼저다. [강제 엔딩 데이터](rakoko_forced_ending.design.json)를 참조한다.

## 장 전환과 저장

엔딩 전에는 같은 장이다. 해가 바뀌거나 주년을 축하해도 family 사용 기록·현재 기획 상태를 초기화하지 않는다. 엔딩을 본 뒤 같은 일지로 진행하면 새 장에서 현재 기획 상태를 새 ID로 시작한다. 원자료 1회 제한·재등장 간격·family 발생 기록은 같은 일지 누적이므로 유지한다. 완료 기획은 보관한다. 업적은 같은 runId 전체 누적이므로 초기화하지 않는다.

날짜·방송 회차·최근 기능군 간격·옷장·미완료 약속·도전·준비도·전체 일지·처리된 달력 키를 유지한다. 결말의 후일담은 서사적 미래 장면이고 게임의 날짜를 몰래 이동시키지 않는다. 계속 방송에서는 결말에 맞는 다음 기획을 제안하되 편성은 플레이어가 다시 정할 수 있다.

세이브에는 ending의 마지막 검사·다음 검사 가능 날짜·검사 방송 ID·당첨 결과·사건 ID·선택 스냅샷·선택 ID·END ID·기획 ID·장 ID·결말 스냅샷·후일담 프로필을 저장한다. 업적 상태와 실제 도달 엔딩 ID 목록은 따로 둔다. 검사 ID는 runId + chapterId + broadcastId로 고정하고 미당첨도 저장한다. 선택 확정 직전에 추가 RNG를 굴리지 않으며 재개·중복 제출로 다른 결말을 만들지 않는다.

세이브에는 stats·게임별 숙련도·원 결과를 참조하는 경험 기록과 현재 기획 ID도 포함한다. 경험 집계는 기록에서 재계산할 수 있어야 한다.

준비 플래그의 생산자는 선행 일반 사건/기획/리허설이다. 엔딩 사건이 자신의 잠긴 선택을 열기 위해 준비 플래그를 자동 생성하지 않는다. 상세 사건에 필요한 선행 콘텐츠가 연결되지 않은 상태에서는 해당 특수 사건을 활성화하지 않는다. 일반 32종과 강제 1종 모두 현재는 설계이며 실행 가능한 게임 콘텐츠로 구현된 상태는 아니다.

주년마다 자동 결말을 저장하던 이전 설계는 폐기한다. 긴 진행의 사건 공급 문제는 별도 제작 과제다. 반복 정책은 [일반 사건 설계](rakoko_repeat_event_design.md)를 따른다. 과거 일회성 공급 보고서의 수치를 최신 반복 정책의 공급 하한으로 해석하지 않는다.

## 검증 기준

- 2027-01-17 검사 없음, 2027-01-18 적격 방송 종료 시 5% 검사.
- 미당첨 뒤 29일은 검사 없음, 30일 지난 첫 방송 종료는 재검사. 생일·주년 편성은 정상 진행.
- 2028-01-18 일반 검사는 8%. 2036-01-18 무엔딩 run은 강제 결혼, 이전 엔딩을 본 run은 일반 검사 32%. 2037년 이후 이미 클리어한 run의 일반 검사는 상한 35%.
- 2026년에서 2030년으로 이동하면 14%로 한 번만 검사하고 과거 해의 검사를 소급하지 않음.
- 엔딩 보류 뒤 90일, 엔딩 후 같은 일지로 진행하면 365일의 검사 대기를 저장·재개해도 유지.
- 주년 축하만으로 장 초기화 없음. 엔딩 확정 후 다음 방송 생성에서만 한 번 초기화.
- 같은 업적 상태라도 기획 준비가 다르면 적격 사건·선택이 다름. 업적만 채워서는 종결되지 않음.
- 일반 16사건·32종결선택·16계속선택 및 별도 강제1사건/1결말의 참조가 맞음.
- 각 일반 선택의 요구 수치보다 1 낮음/같음, 지정 경험 없음/있음, 다른 게임 경험일 때 잠금 여부가 올바름.
- 잠긴 선택 실행 차단, 계속 선택은 END ID 없음, 종결 선택 하나에서 결말 한 개만 확정.
- 사건 표시 후 종료·재개해도 같은 사건과 선택을 보며, 도달 전 다른 결말 전문을 미리 공개하지 않음.
- 미당첨·당첨·보류·확정·다중 탭 충돌 후 결과와 의상·약속을 중복 변경하지 않음.

최신 사용자 정정: 무조건 진행 가능한 연도 제한 없는 규칙을 무엔딩 10년 강제 결혼으로 대체했다. 일반 선택 잠금은 사건 노출 여부와 분리하며 강제 엔딩은 이 제한을 우회하는 유일한 지정 예외다.

선택 설명이 부족한 능력과 맞는지, 경험 생산자가 실제로 연결됐는지, 마무리 기획을 승인하지 않은 상태에서 일반 크레딧이 나오지 않는지를 추가 검증한다.

9년째부터 무엔딩 10년 강제 종료까지 남은 기간을 달력과 준비 화면에 표시한다. 기한을 넘기는 날짜 선택에는 도착할 실제 날짜와 강제 엔딩을 미리 안내한다. 이 지정 예외도 숨겨진 랜덤 조우처럼 느껴지지 않게 한다.

장기 서버·공대·대회·협동 기획을 추가했다. 콘텐츠 시즌 종료는 방송일지 엔딩이 아니다. rakoko_long_content_bridges.design.json의 실제 검증 결과만 경험 생산으로 연결하고, 모듈 완료 후 제안하는 엔딩 기획도 플레이어 승인·수치·경험·현재 준비를 다시 요구한다. 기존 일반32+강제1결말은 유지한다.

방송 자금 정산은 일반 엔딩 검사 전에 한 번 확정한다. 구매비 지출은 수치·경험·준비를 면제하지 않으며 잔액 부족 시 유료 작업을 포기하고 방송을 이어갈 수 있다. 무엔딩10년 강제결혼은 비용0원으로 자산 부족과 관계없이 적용한다. 경제 원본은 rakoko_economy.design.json이다.
