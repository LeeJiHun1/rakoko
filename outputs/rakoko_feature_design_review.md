# 기능 설계 검토 결과

2026-11-04 · 정적 문서·데이터 연결 검토. 실행 코드 테스트나 플레이테스트 결과가 아니다.

대상: `rakoko_game_feature_spec.md`, `rakoko_outfit_feature_design.md`, 의상 manifest와 rules.design.json. 기준은 사용자 확정 요구사항, 상태 전이의 완결성, 중복 처리, 저장 복구, 콘텐츠·에셋의 실제 확보 범위다.

## 상태 전이 시나리오 대조

|입력 시나리오|명세가 요구하는 결과|
|---|---|
|기본 상태에서 경찰복 환복|잠금 설명, 착용 변경 없음|
|준비 25에서 방송 시작|유출 부적격, 일반 사건 진행|
|준비 50에서 유출 없음→종료/재개|검사 완료 유지, 해당 방송 재추첨 없음|
|일부 유출→티저로 넘김|전체 잠금 유지, 준비·예약 보존, 재유출 금지|
|일부 유출→수습 성공|준비 재개, 소모 행동 추가 없음|
|일부 유출→즉시 공개|영구 해금, 예약 교체, 이전 의상 유지|
|일부 유출→확률 수습 실패|동일한 조기 해금, 실수 공개 기록|
|공개 선택 중 더블클릭|동일 명령·사건 재적용 거절|
|공개 저장 후 연출 도중 종료|재개 시 해금 유지, 연출만 재생/건너뛰기|
|환복 100회|성장·보상 변화 없음, 마지막 착용만 저장|
|의상 준비 중 다른 의상 시작|이전 진행·유출 보존, 새 활성 준비 대상으로 변경|
|예약 코너 직전 일반 유출 검사|예약 공개 슬롯에서는 검사 생략|
|조건 만족 일반 사건 0개|코너별 일상 사건, 빈 선택 화면 없음|
|후속 4개·남은 코너 1칸|우선 1개 진행, 나머지 대기열 유지|
|새 콘텐츠 버전에 진행 사건 삭제|세이브 사건 스냅샷으로 재개|
|오래된 탭에서 선택 제출|revision 충돌 표시, 최신 세이브 다시 읽기|
|전신 PNG 로드 실패|현재 의상 ID 보존, 텍스트/기본 실루엣 대체와 재시도|

위 표는 요구 결과의 논리 대조다. 구현 후 실제 동작 검증 목록으로 사용하며 ‘테스트 통과’로 보고하지 않는다.

## 구현 전에 남은 제작 항목

- 코너별 반복 일상 사건, 일반 사건의 선택 비용·후속 결과, 엔딩 문구를 플레이용 데이터로 작성해야 한다. 기존 사실 조사 카드는 즉시 실행 가능한 이벤트 데이터가 아니다.
- 의상 유출용 부분 단서 이미지와 의상별 선택 아이콘은 미제작이다. 현재 정지 전신 4종과 공용 커튼 배경은 확보했다.
- 원음·화자 대조가 끝나지 않은 말투를 실제 인용으로 사용하지 않는다. 이 검토가 자료 수집 완료를 뜻하지 않는다.
- 준비 행동 2회·코너 3칸·기본 방송 간격·유출 확률은 사용자 미확정의 조정용 기본안이다. 첫 플레이에서 길이·반복 빈도·의상 준비 부담을 확인해야 한다.

## 검토 판정

사용자가 확정한 의상 기능은 구현 가능한 상태 규칙으로 정리했다. 높은 중요도의 문서상 누락은 수정했으며 구현을 막는 추가 사용자 질문은 현재 없다. 전체 게임은 설계 초안으로 연결됐지만 밸런스·재미·콘텐츠 분량·실행 안정성 검증은 아직 남아 있다. 다음 작업은 상태·저장·일상 사건을 포함한 한 회차 구현부터 시작하는 것이 순서다.

최신 검토: 일반32결말에 상태2개·경험·현재기획 준비를 연결하고, 사건표시와 선택실행 권한을 분리했다. 엔딩 기획 승인/예약/종결 선택으로 갑작스러운 일반 종료를 방지한다. 무엔딩10년 강제결혼은 별도1결말이며 일반확률·잠금보다 우선한다. 반복형 일반55참조·전체105참조312선택의 규칙은 rakoko_event_play_rules.design.json을 따른다. 이전 모든family1회 및 무기한무엔딩진행 기준은 폐기했다.
