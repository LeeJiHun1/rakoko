# 80억분의 1 직접 플레이 기록

2026-11-03 · [공식 사이트](https://1in8b.life/ko/) · 표시 버전 v0.9.17 베타

## 범위

브라우저에서 실제 버튼을 눌러 한 삶을 진행했다. 현재 세상·출생아 기준·약 30분 설정으로 시작했고, 진행 도중 16배속과 다음 결정까지 기능을 사용했다. 심한 장면을 줄이는 옵션을 켰다. 따라서 기본 설정의 모든 사건을 관찰한 플레이는 아니다. 20세부터는 게임 내 자동 결정 기능으로 후반 흐름을 관찰했다. 전체 분기나 수식은 검증하지 않았다.

**87세 종료 화면까지 도달했다.** 가상 인물 허위쩌는 정비 팀장으로 일하다 은퇴한 것으로 결산되었고, 남긴 자산은 한국 체감 1.3억 원으로 표시되었다. 자동 결정 비중이 높아 개인별 누적 성향 결과에서는 제외된다는 안내도 확인했다. 결과 이미지 저장 버튼은 눌렀으나 다운로드 완료를 확인하지 못해 이미지 파일은 산출물에 포함하지 않았다.

## 돈 쓰기·투자는 별도의 중요한 조작층

사용자의 지적으로 메뉴를 실제 열어 추가 조사했다. 단순한 장식이나 일회성 카드 묶음으로 보면 구조를 놓친다.

- **즉시 소비**: 선물·여행·장비 등. 화면에 가격과 효과 방향이 안내됨.
- **성장/기회 준비**: 훈련·이직 준비·새 직업 도전. 후속 기회를 여는 행동이 포함됨.
- **지속 정책**: 여유 자금 운용, 지출 방침, 생활 방식. 반복되는 연간 결과에 관여함.
- **자동 실행**: 주기적 행동을 켜두는 옵션이 있으며 자금 조건 안내가 있음. 옵션 목록은 읽었지만 모두 켜서 검증하지는 않음.
- **조건과 대기**: 나이·보유금·기존 상태에 따라 메뉴가 달라지고, 일부는 빚으로 가능하며 일부는 불가. 훈련 뒤 대기를 직접 확인함.

주식·채권 혼합 운용에서 손실이 난 해와 수익이 난 해를 각각 관찰했다. 한 번의 플레이로 변동성 분포나 평균 수익률을 실측한 것은 아니다. 게임 화면의 금융 수치도 실제 투자 조언이나 이 문서의 검증 결과로 옮기지 않는다.

## 라코코 게임에 주는 결론

종료 화면에는 경력·가족·취미·자산·가장 행복했던 해·시간을 쓴 활동·회고·네 축의 삶 요약과 공유 기능이 있었다. 결산은 단일 승패가 아니라 플레이 중 누적된 여러 요소를 다시 보여준다. 이 구조를 위해 라코코 쪽도 사건별 회고 태그와 처음의 목표가 나중에 어떻게 달라졌는지를 모아야 한다. 결과 공유 기능의 존재는 확인했지만 외부 게시나 공유는 하지 않았다.

사건만 랜덤으로 뿌리지 말고, 방송 전 준비·방송 중 운영·능동 관리·예약 사건·기록 회고를 함께 만든다. 특히 장비·연습·자료·합방 준비는 ‘메뉴에서 먼저 선택하는 행동’이 될 수 있다. 기존 사건 카드는 발생 조건과 후속 연결을 보강해야 한다.

상세한 수집 항목과 우선순위는 `rakoko_game_data_plan.md`, 기록 양식은 `rakoko_collection_template.json`을 참조한다. 원작의 통계 기반 인생 엔진을 그대로 쓸 필요는 없으며, 라코코 자료의 관찰 근거와 게임 확률을 분리한다.

## 해석 한계

[공식 소개](https://1in8b.life/ko/about/#life)도 일상 초점과 주요 결정이 병행되고 선택은 결과를 보장하지 않는다고 설명한다. 브라우저에서 직접 읽어 플레이 관찰과 대조했다. 전체 생애 길이는 정해진 기대수명에 고정되지 않는다는 설명도 확인했다.

- 비교할 두 번째 출생 조건이나 동일 조건 반복 실험은 수행하지 않았다.
- 자동 진행 중 발생한 모든 사건을 일일이 검토한 것은 아니다.
- UI에 보이는 선택 효과와 실제 내부 수식은 구분한다. 숨은 확률·전체 카드 수·전체 엔딩 수는 미확정이다.
- 공개 API 소개는 별도로 확인했으나 API 키 발급이나 엔진 API 사용은 하지 않았다. [공식 API 안내](https://1in8b.life/ko/api/)는 본 게임의 구조 참고용이다.
