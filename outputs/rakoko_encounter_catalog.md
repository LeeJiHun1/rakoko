# 라코코 방송 랜덤 인카운터 확장

2026-11-04 · 창작 설계 72종. 사용자가 방송에서 벌어질 만한 일의 창작을 허용하여 작성했다. 실제 사건 72건을 조사했다는 뜻이 아니다. 기존 조사 카드 29개와 중복 주제가 있으므로 101개 독립 사건으로 합산하지 않는다. 선택 결과는 구현 전 설명이며 실행 효과·완성 대사는 아니다.

## 운영 규칙

- 일반 랜덤, 조건 후속, 결과 반응, 예약 이벤트 변주, 방송 후 작업을 구분한다. 72종 전부가 언제나 추첨되는 것이 아니다.
- 불리한 해프닝만 연달아 등장하지 않게 같은 기능군은 2회 방송 간격을 두고, 같은 정의는 시즌당 1회가 기본이다. 평범한 반복 일상은 별도 풀이다.
- 일반 사건 추첨은 긍정 기회/해프닝/중립 참여 가중치 30/30/40을 조정용 초안으로 둔다. 후보가 없으면 다른 적격 풀로 재분배한다. 슬롯당 사건 1개 원칙을 유지한다.
- 앞선 선택이 만든 후속은 난수로 소멸시키지 않는다. 도래한 후속은 대기열에서 처리한다. 성공 반응 사건은 이미 성립한 결과를 전제로 하며 무작위로 승리 기록을 만들지 않는다.
- 기념일·공개 예약이 우선하며 해당 코너는 일반 추첨을 대체한다. 의상 유출은 기존 유출 엔진의 훅으로만 연결해 8% 추첨과 일반 풀 추첨으로 중복 발생시키지 않는다.
- 사용자의 코너 편성으로 후보 풀이 줄 수 있다. 전체 정의 수 외에 코너별 적격 후보 수·같은 기능군 재등장 간격·선택 경로 차이를 플레이에서 확인해야 한다.
- 실제 사건 카드에서 각색할 때 같은 `familyId`로 통합한다. 기술 문제의 이름만 바꾼 여러 카드가 연속해서 나오지 않게 한다. 아래 72개가 모두 독립된 새 게임 시스템이라는 뜻은 아니다.
- 선택의 유불리는 하나의 인기 점수로 통일하지 않는다. 자료 보존·편성 변경·도전 단계·약속 생성·외형·일지 등 서로 다른 결과로 남긴다.
- 라코코 직접 인용문은 생성하지 않았다. 타 스트리머 이름·실제 팬 게시물·유료 음악·오컬트·심각한 사고는 자동 삽입하지 않는다.
