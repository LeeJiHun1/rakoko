# 게임 완성도 검증 계획

2026-11-05 · 36시나리오 · P0 23 / P1 13 · 게임 실행 검증0건

모든 항목은 **실행 전**이다. JSON·참조·파일 크기를 검사한 정적 감사와 아래의 실제 게임 검증을 구분한다. 제안 수치를 게임 설정에 자동 적용하지 않았다.

## 우선순위와 통과 증거

- P0: 진행 막힘, 잘못된 엔딩/보상/결제/저장으로 이어질 수 있는 항목. 첫 시연에서 대표 경로를 검사한 뒤 전체 경로로 확장한다.
- P1: 선택 이해·속도·반복·읽기·조작·마감 품질. 출시 전에 실제 화면과 플레이로 확인한다.
- 미정 정책은 먼저 결정해야 하며, 구현 전 테스트 계획이 있다는 이유로 통과 처리하지 않는다.
- 결말별 재현 로그는 `새 게임 상태 → 명령/선택 → 비용/성장 → 실제 EX 생산 → 현재 기획 → 종결`을 포함한다. 고정 시드와 콘텐츠/저장 버전을 함께 남긴다.
- 무작위 진행은 분포·막힘 탐색에 사용하고, 희귀 결말은 별도 목표 경로로 증명한다. 200시드×52회×4방침은 제안 예산이며 이번 수행 수가 아니다.

### QA-030 · 본문과 조건 설명의 대비 (P1 / 접근성)

- 재현: 모든 배경·의상·명암 설정에서 본문과 잠금 설명의 대비를 측정한다.
- 기대: 일반 설명4.5:1·큰 글자 기준의 제목3:1을 확인한다. 잠금 정보를 색만으로 전하지 않는다.
- 상태: 미실행.
- 조사 연결: [QS-10](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

### QA-031 · 음소거·동작 줄이기·군중 표시 (P1 / 연출)

- 재현: SFX/BGM 음소거·동작 줄이기·반응 접기·즉시 표시를 선택한다.
- 기대: 결과 의미를 잃지 않고 필수 클릭·대기가 늘지 않는다.2줄 이상 반응은 기존 최소2가상 화자 규칙을 따른다.
- 상태: 미실행.

### QA-032 · 이미지 실패와 부분 유출 범위 (P1 / 연출)

- 재현: 이미지404·로딩 지연·의상 미공개/일부 유출/공개 완료를 표시한다.
- 기대: 대체 이름·재시도와 진행이 가능하다. 일부 유출에 전신이나 미공개 지식을 보여주지 않고 로딩으로 선택 위치가 튀지 않는다.
- 상태: 미실행.

### QA-033 · 로딩·입력·레이아웃 안정 (P1 / 성능)

- 재현: PC/모바일 조건을 고정하고 초기 표시와 반복 선택을 측정한다.
- 기대: LCP≤2.5초·INP≤200ms·CLS≤0.1을 목표로 한다. 실험실 결과를 실사용75백분위 달성이라고 표시하지 않는다.
- 상태: 미실행.
- 조사 연결: [QS-15](https://web.dev/articles/vitals)

### QA-034 · 처음과 재플레이의 속도 (P1 / 사용자 플레이)

- 재현: 우선 팬4명·사전 지식 적은4명 정도로 첫 플레이와 재플레이를 관찰한다.
- 기대: 읽기·설정·반복·대기·엔딩까지 시간을 나눠 기록하고 잠금 이유·다음 준비 이해를 확인한다. 첫 일반 엔딩15~25분안을 검토하며 모집단 평균으로 주장하지 않는다.
- 상태: 미실행.

### QA-035 · 글꼴·그림·음향 최종 점검 (P1 / 에셋)

- 재현: 실제 표시 크기의 눈·머리·의상 구분·알파 경계, 한글 글리프, 선택/확정/잠금/완료음을 확인한다.
- 기대: 글자 깨짐 없이 읽기 쉬운 대체 글꼴과 필요한 고지를 제공한다. 미확보·미청취 음원을 채택 완료로 표시하지 않는다.
- 상태: 미실행.
- 조사 연결: [QS-14](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/101), [QS-16](https://kenney.nl/assets/ui-audio), [QS-17](https://neodgm.dalgona.dev/embedding_fonts.html), [QS-18](https://github.com/google/fonts/blob/main/ofl/notosanskr/OFL.txt)

### QA-036 · 제외 소재와 엔딩 안내 범위 (P1 / 내용 일관성)

- 재현: 사건·변주·후일담·채팅 반응을 읽고 새 게임의 엔딩 안내를 확인한다.
- 기대: 오컬트 서사·심각한 사건·타 인물 환생은 제외한다. 미경험 실적·미도달 결말을 단정하지 않되 현재 기획의 다음 준비는 알 수 있다.
- 상태: 미실행.

## 첫 플레이 관찰 기록 양식

|항목|기록 내용|
|---|---|
|환경|게임/콘텐츠/저장 버전, 기기·브라우저·화면 크기|
|플레이 배경|팬/사전 지식 적음, 첫 플레이/재플레이. 실제 닉네임 수집 불필요|
|진행|첫 방송/첫 일반 결말 시간, 완료 방송·사건·실제 선택 수|
|시간 분해|읽기, 준비/편성 설정, 반복 연출, 다음 목표 탐색, 중단 시간|
|이해|선택 전 의도·잠금 이유·다음 준비·날짜 이동의 영향을 설명할 수 있는지|
|상태|규모 승급·현금 부족 포기·반복 family·선행 경험 확보 시점|
|문제|장면·재현 명령·기대/실제 결과·중요도·재시험 여부|

8명 파일럿은 초안 문제를 찾는 제작 제안이며 모집단의 평균 시간·만족도 통계를 주장할 수 없다. 이 문서는 외부 사람에게 연락하거나 사용자 데이터를 전송할 권한을 부여하지 않는다.
