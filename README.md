# 라코코의 방송일지

> 오늘의 방송이 내일의 이야기가 되는 곳. 라코코와 키몽이들을 위한 **비공식 선택형 팬게임**.

준비하고, 방송하고, 기억할 장면을 일지에 남기는 브라우저 게임입니다. 설치할 패키지 없이 Node.js 만 있으면 바로 실행됩니다.

## 실행

```bash
npm run dev      # http://127.0.0.1:5173 — 개발 서버 (포트 변경: PORT=5391 npm run dev)
npm test         # 엔진 규칙 테스트 + 32개 결말 실제 도달 확인 + 골든(동작 고정) 테스트
npm run check    # 카탈로그·이미지 경로·JS 문법·코드 속 콘텐츠 ID 검사
npm run build    # dist/ 정적 산출물 생성 (정적 호스팅에 그대로 올림)
npm run preview  # dist/ 미리보기
```

- 요구 사항: Node.js 16.15 이상. 외부 npm 패키지를 쓰지 않습니다.
- 저장: 브라우저 IndexedDB 에 자동 저장됩니다. 다른 기기로 옮길 때는 설정 → 일지 내보내기/가져오기.

## 플레이 흐름

1. **준비** — 방송마다 준비 행동 2번. 자료 준비(잡담·팬 참여·특별 기획 코너 유리)·게임 연습(게임 코너 유리)·화면 점검(모든 코너 실수 감소)·의상 준비.
2. **방송** — 코너 3개. 선택지는 **안정·보통·모험** 성향이 있고 결과가 **대성공·성공·아쉬움**으로 갈립니다. 대성공이면 채팅이 폭주하고, 확률로 **가상 응원**이 터집니다. 코너 사이에 **구매 이벤트**(비쌀수록 후반)와 **새 의상 제안**이 나오기도 합니다.
3. **일지** — 세 코너 결과와 **시청자 성장**으로 방송 등급(S~C)이 매겨지고, 최고 시청자·수입·역대 기록(NEW RECORD)이 정산됩니다.
4. **목표** — 기획을 골라 자료 → 시범 → 피드백 3단계로 완성하고, **방송 150일째부터** 마지막 특집으로 결말(32종)을 만납니다. 여러 기획을 완성해 두고 결말 때 고를 수 있습니다. 결말 없이 10년이 지나면 특별한 결말이 있습니다.

## 즐길 거리

- **신의상 4종** — 방송 중 제안 → 시작(200만원) → 준비(무료) → 커튼 공개 → '지금 입기'. 준비를 미루면 유출될 수 있고, 덜 준비한 채 공개하면 실패할 수도 있어요.
- **이번 달 미션** — 매달 3개, 달성 보상과 도장.
- **업적 25종·사건 도감 80종·결말 모음 33칸** — 지난 기록 탭.
- **시청자 추이 그래프·결산** — 지난 기록 탭.
- **편의** — 키보드(숫자 1~4 선택, Enter 다음), 글자 크기 125~200%, 동작 줄이기, 효과음, 일지 내보내기/가져오기.

## 폴더 구조

```
index.html          진입 페이지
src/engine.js       게임 엔진 공개 진입점 (구현은 src/engine/*)
src/ui/             화면·입력 처리 (views/* 화면별)
src/styles/         영역별 CSS (src/style.css 가 순서표)
src/data/           catalog.json(실행 콘텐츠) · chat.js(채팅 반응)
scripts/            dev 서버 · 빌드 · 검사 · 콘텐츠 컴파일러
tests/              엔진 테스트 · 골든 테스트 · UI 비교 시나리오
assets/             캐릭터·의상 이미지, 글꼴
outputs/ · work/    조사·설계 기록과 그 생성 스크립트 (실행에는 쓰지 않음)
docs/               아래 문서
```

## 고지

- 라코코 및 관련 크리에이터와 **무관한 비공식 팬 창작물**입니다. 실제 발언·방송 결과를 재현하지 않습니다.
- 캐릭터 이미지는 사용자 제공 참조를 바탕으로 만든 도트풍 이미지입니다. **공개 배포 전에 라코코 측 2차 창작 가이드라인(AI 생성 이미지·후원 묘사·팬게임 배포)을 확인하고, 허용되는 범위에서만 공개합니다.**
- 방송 다시보기 캡처 등 참조 원본은 저장소에 포함하지 않습니다(`.gitignore`).
